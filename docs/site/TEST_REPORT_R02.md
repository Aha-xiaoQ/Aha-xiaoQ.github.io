## 不能据此声称完成的部分

浏览器环境对 `http://127.0.0.1` 与 file URL 导航返回 `ERR_BLOCKED_BY_ADMINISTRATOR`。没有更改或绕过该策略。离线 DOM 测试移除了网络加载标签，加载了已核对的原站样式文本；存储和导出使用替身，生命周期测试对模块作了离线作用域适配。

因此，本轮没有完成真实跨 URL 导航、浏览器前进后退、View Transition、CSS/ES module 网络加载、CSP、真实 localStorage 刷新恢复、原生下载、霞鹜文楷/背景图片加载的验收。语言按钮与翻译管理仍复用原站，真实双语流程留待发布者验证。截图若用于检查，只是字体与图片回退下的离线布局，不是上线截图。

`npm run check` 的完整资源检查在制作环境缺少原站字体等资源时会提示缺失；没有通过伪造字体文件来把它标为成功。请在你原有的完整仓库运行该命令。R02 已修正两套旧校验器对站点根相对链接的处理，并允许新的 site-shell 缓存版本。

Windows 双击 CMD、真实磁盘权限、GitHub Actions/Pages 部署、三期游戏通关、实体手柄、音频听感均未在本轮验证。没有远端推送或配置修改。

## 发布者必须补验

在完整仓库应用后执行 `npm run check`、`npm test`、`npm run test:site` 和 `npm start`。从首页进入开发页，再进入笔记、游戏、返回开发；对比主导航、页头、页脚和字体。直接打开旧地址、刷新、前进/后退；保存草稿后切换栏目并返回、导出、刷新恢复；检查中英文导航和手机宽度。

全部通过再由维护者手动提交推送，把实际 commit 和 Pages 结果写回原状态文件。本次本地通过不能自动把待验收任务标为已完成。
