## 测试环境与不能据此声称完成的内容

Node.js 22.16.0 / Linux / 系统 Chromium。测试目标是通过已交付的 R01、R02 文件构建的缩减工作区：使用实际状态、模型、界面和原生 shell/router 代码，外层页面模板、站点数据及 i18n 使用简化测试替身；不是下载成功的全站。

制作环境对外 DNS 请求失败。浏览器尝试访问本地 HTTP 时返回 `ERR_BLOCKED_BY_ADMINISTRATOR`，未更改或绕过策略。浏览器改为 about:blank 的 DOM fixture：载入已读取的主题/内容 CSS，注入组件，资源读取、下载和存储使用替身。模块仅为离线测试作了作用域适配；实际发布文件仍是 ESM。

因此 **未完成** 真实跨 URL 跳转、前进/后退、原生 View Transition、完整 ESM/CSP/网络资源加载、localStorage 刷新恢复、真实文件下载、中英文全流程、原站字体/图片背景与完整首部资源的端到端验收。页面组件的原生导航入口和路由规则已检查，但不能把规则检查写成动画已实测。布局截图属于字体/图片回退下的本地组件预览，不是完整网站实拍。

完整仓库 `npm run check` 所需的站点媒体/静态入口并未在缩减 fixture 中假造为已具备；必须在用户完整仓库运行。Windows CMD、实际文件权限、GitHub Actions/Pages、游戏通关、实体手柄和音频均未验证。未修改远端配置、未提交或推送。

## 发布者补验

运行 `npm run check`、`npm test`、`npm run test:site` 和 `npm start`。逐页打开、刷新、前进/后退；从任务切到文档再返回；编辑后导出并核对 JSON；刷新草稿、键盘/触屏和手机排版；比较主站主题、语言和转场。再检查原游戏与下载链接。

通过后由维护者手动提交推送，把实际提交及部署结果写回原共享记录。本次没有把任何旧游戏任务改成“已完成”。
