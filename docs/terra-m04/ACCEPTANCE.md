# 发布前清单

先执行源码verify、prepublish:check，以及原网站check/test。自动产物一致性不等于批准上线。

1. Windows完整仓库验证安全路径、构建和下载；不能把Linux结果冒充Windows通过。
2. 默认候选只显示正式第三期入口；明确?dev=1才出现试验场。进入/退出实验、设置开关、暂停与恢复不串状态。
3. 第三期移动/跳跃/换武器/箱子/拾取/隐藏关/奖励/返回自然流程；实体手柄、触屏、音频与存档。
4. 网页资料只有三个主要入口，历史details默认关闭；旧源码和原资料直链存在。R12小图标、颜色、字号、转场不退化。
5. 从实际网站下载M04 source.zip，在干净目录verify并构建；检查安装源码与ZIP一致。根游戏稳定页面仍原文件。
6. 将真实结果和候选SHA写进RELEASE_REVIEW，不默许第三方素材再分发。审核后才手动提交推送，另查远端CI与Pages。
