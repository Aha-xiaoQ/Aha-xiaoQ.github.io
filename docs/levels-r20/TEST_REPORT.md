## 发现并修正

单房间测试原来只改入口，导致地下 1-2 的旧入场房间在单向图中不可达。现通过临时会话的可达子图创建单房间测试，不向底图添加虚假传送门；新增回归覆盖八房间。生成工具改为先核对所有输出再写入，后面的生成文件冲突不会导致前面文件已更新；手改草稿也参与契约验证。

新的地图活动不应改变第三期的版本指针。增加 `kind=content`，更新检查仍对真实游戏 release 记录核对，旧无 kind 条目保持原兼容语义。没有关闭当前源码与版本一致性检查。

安装测试最初把当前任务路径写成过时文件名，改为读取项目实际 `state.path` 后重新通过；旧任务内容的字节保护断言保留。原版核验标为 reviewed 时必须提供审核人与证据字段，默认全部 pending。

## 环境与限制

Linux / Node.js 22 / 系统 Chromium / Python Playwright。本地 HTTP 浏览器探测返回 `ERR_BLOCKED_BY_ADMINISTRATOR`，未改变或绕过策略。工作台在离线 DOM 环境执行真实模块与数据，网页预览用实际生成 HTML、原 CSS 文本和真实结构 SVG，未含原站完整字体、背景与真实路由。M06 检查执行完整生成 HTML，禁用远程请求。

未验证：Windows 原生、真实 HTTP/ESM/CSP、原生下载与前进后退、物理手柄/触屏、自然通关、敌人和机关原版时序、原作素材授权、外部贡献者 PR 与远端部署。模板角色为几何样例，原泰拉角色/武器/坐骑尚不能任意用于新地图。1-4 模板不代表奥日关卡已经完成。
