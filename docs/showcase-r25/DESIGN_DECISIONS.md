# R25 设计与组件约定

## 两个问题分别解决

操作区的问题是同一组目标使用按钮、下划线文本、格式标签三套语言，层级不清。R25 统一轮廓、间距和高度，只保留一个主要操作。不是给所有链接套按钮；正文、下载资料与导航依旧使用原来的语义。

关于页不堆技能雷达、履历统计或未经确认的个人信息。用已有头像、姓名、工作室名片和留言卡形成个人识别，再以用途说明区分联系渠道。保留红黑米白及原素材，不另做一套品牌。

## 参考

Carbon Design System，Button / Usage（本轮核对）：https://carbondesignsystem.com/components/button/usage/ 。借鉴同组操作尺寸一致与明确主次；本站仍保持链接的原生导航语义，不照搬企业产品的整体外观。

主站固定参考资源：Aha-xiaoQ/Aha-xiaoQ.github.io，提交 ed76f0b668a9e7c1a8d8f71bed2489cb2b063c9e 的 site-theme.css、site-shell.css、about/index.html。既有头像和字体继续由该站维护；本包不附带字体。

## 行为约定

新视图无事件监听、无 fetch、无存储，真实 href 由浏览器和原路由处理。可见联系名配用途说明；图标为装饰，不可独立充当无文字按钮。留言卡一个目标，禁止嵌套链接。CSS 不声明全局主题、字体或路由过渡，容器不足时操作组两列布局。减少动态效果和系统强制色提供降级。

新增界面词条扩展既有 SITE_EN，不替换词典对象；完整英文长文案与所有既有词条仍需实机检查。本轮不宣称整站通过无障碍认证。
