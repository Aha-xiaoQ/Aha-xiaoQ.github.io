## 保留与合并

默认旧联系区域前后静态附加内容保留。定制头像、介绍、留言标题、联系地址、非标准结构或活动脚本导致预检停止；维护者先核对，再明确合并，不提供 force。安装记录只能用于识别此次状态，后续编辑应通过正常源码和 Git 管理。

## 当前证据边界

网站测试是组件/构建/发布检查，不等于完整线上验收。浏览器在 set_content 下执行实际视图和CSS，原品牌字体缺失时用本地楷体替代；封面与头像预览像素来自本次用户截图。裁片不安装，实际页面仍引用原文件。测试外围截短的 kicker 样式按已读取固定提交补足，只服务截图，不进 payload。

下一步在完整站点验收直开/跳转、中英文切换、留言服务、真实下载与浏览器缓存。新的设计改动须同步源码、生成文件和下载发布，不禁用 R24 审计。未推送或部署。
