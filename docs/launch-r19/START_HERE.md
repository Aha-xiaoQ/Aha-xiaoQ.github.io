# R19 · 观众访问流程与上线核验

基于 R18；最终合集可从 R17 一次应用 R18 与 R19。当前游戏仍为 0.4.2 / M06。网站主题、主导航六项、小图标、游戏单条列表和游戏源码保持原有范围。

## 改动

游戏介绍先突出“开始试玩”，视频和下载是次要操作；手机先显示开始面板。新建 `/play-guide/` 试玩帮助、`/404.html` 错链恢复；当前源码页提供返回已发布试玩的文字入口。引导和介绍使用原站页头与原生路由，静态和动态开始区共用同一组件。

增加明确触发的“复制本页链接”，失败后提供可选取文本；复制不带查询参数或锚点，不自动采集或上传。图片失败保留信息和试玩入口。帮助进入本地搜索索引。

## 运行

先运行 `npm run launch:check`、`npm run test:launch`，再运行原 `experience:check`、`release:preflight`、`check`、`test`。完整网站使用 `npm start` 或 `npm run dev`。

`launch:audit` 检查当前登记页面及直接的本地引用，报告缺失文件、锚点、重复标题/ID和大图。只检查 HTML 直接引用，不等于完整 CSS/JS 依赖扫描、外网可用性或性能测量。缺失真实资源时退出非零；不要通过伪造文件或删除检查绕过。

## 验收

阅读 `AUDIENCE_REVIEW.md`、`RESEARCH.md`、`ACCEPTANCE.md`、`TEST_REPORT.md`、`HANDOFF_R19.md`。报告中的评分是主观设计审阅，不是用户调研、Lighthouse、行业排名或上线批准。

源码协作仍在原三个主要资料入口，历史未删除；本轮不扩展游戏引擎或引入城堡。页面中文为主，完整英文、Windows及真正浏览器网络仍需实机验收。
