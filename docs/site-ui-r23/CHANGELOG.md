# R23 变更记录

网站共享界面版本 site-ui-r23。游戏仍 M07/0.4.3，地图工具仍 W02/0.2.0。

## 用户可见

小屏菜单、搜索标签/结果计数/清除、中文输入法交互、当前资料面包屑、模板宽版与键盘横向浏览、内页标题和正文层级、深浅卡片焦点。

## 实现

新组件接入原 experience 生命周期，增加窄范围页眉观察与幂等装配。静态、懒加载模块 URL 统一。没有第二个路由或转场。原生成器仍从当前仓库的真实内容创建页面；手改生成页阻止覆盖。

## 保护

不改游戏源码、WorldKit、模板数据、已发布试玩、下载 ZIP、任务、项目介绍/负责人/版本状态、字体、品牌图、现有小图标。首页和其他原生HTML只更新组件资源接入，不替换正文。

## 验证边界

检查数据、静态结构、离线浏览器布局与交互，不代表完整线上性能、自然游戏通关或辅助技术认证。详见 TEST_REPORT 与 ACCEPTANCE。
