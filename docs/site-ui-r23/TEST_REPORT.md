## 检查中的真实发现

首轮既有网站测试有5项失败：旧断言仍要求历史缓存号。在核对期间发现路由懒加载的体验模块URL仍硬编码为experience-r18，而静态入口已升级；这可能导致两个模块实例及重复监听。已修正唯一的懒加载URL，并保留静态/动态URL必须相同的新检查。随后只更新既有缓存号期望，原交互、图标、数据和路径保护断言保留，312项回归全部通过。

最初离线渲染未在动态重绘后恢复原SVG传输，造成预览图标缺失；已让测试装载器使用同字节SVG并重截，未用新图替代。首版开发页重复标题占空间，已缩短为“项目进展”。另补测“只替换导航子树”和“单独移除菜单按钮”的恢复；组件能重新接管新节点，避免旧监听器残留。语言工具条使用已读取的真实公开CSS片段作为明确的测试夹具，不改生产词典或品牌CSS。
