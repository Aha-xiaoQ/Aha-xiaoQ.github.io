# 面向观众的文案

公开首页回答三个问题：这里有哪些作品？最近发生了什么？我能从哪里体验或参与？不要用安装回执、内部版本号、源码路径、聊天过程和构建解释占据首屏。

“从项目开始”改为“正在打磨的作品”，“这个项目在做什么”改为“关于这个作品”。技术资料中再解释输入模块、候选构建与架构；不能把技术细节删掉，只是放到适合的层级。

项目阶段、单项任务、发布验收是三种状态。已发布要有实际依据，待验收不改成上线；不将任务数量换算成整个游戏完成率，不捏造参与人数与发布日期。现有项目摘要和历史更新继续读取原登记文件，本包没有批量重写用户数据。

当前导航称“开发 / Dev”，它承载多个项目，不叫“混合马里奥后台”。旧日志中“开发日志”属于当时的内容，不做全文替换。英文导航与系统标签支持切换，项目长篇原稿目前仍为中文，不声称已经全文双语化。
