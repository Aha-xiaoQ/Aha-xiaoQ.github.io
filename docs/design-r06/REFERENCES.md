# R06 参考依据

参考只用于组织与交互原则，没有拷贝第三方视觉资源、字体或代码。本轮查阅日期：2026-09-15。

- SGDS Card：https://www.designsystem.tech.gov.sg/components/card 。借鉴标题、摘要、媒体、单一主要操作的卡片层级；避免将太多互相竞争的内容塞进一张卡片。
- Linear UI redesign：https://linear.app/now/how-we-redesigned-the-linear-ui 。参考信息层级与主次控制，保留本网站自己的平面拼贴风格，不仿制 Linear 的产品后台。
- MDN prefers-reduced-motion：https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion 。组件悬浮效果尊重减少动态效果设置；不另写整页转场。
