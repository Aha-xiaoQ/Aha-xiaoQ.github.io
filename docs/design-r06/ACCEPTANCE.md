# R06 发布前检查

先备份或提交本地修改，在完整仓库运行 `npm run check`、`npm test`，然后使用原启动命令。

1. 首页、项目、游戏、工具、开发、关于来回切换；始终为原六项主导航，首页快捷入口不再写“笔记”。
2. 项目卡可看到 Q咪原动画与真实图像；无图项目有抽象图形而不是破图。游戏试玩/介绍/视频/下载链接全部保留。
3. 开发目录的搜索/类型筛选正常，项目和详情没有串数据；任务分页、状态筛选、展开条件可操作。
4. 项目详情、资料、更新、参与和维护子页可直达刷新；返回/前进与减少动态效果遵循原站转场。
5. 320px、390px、768px、常用桌面与 200% 浏览器缩放检查；焦点可见，正文不倾斜、不裁字。
6. 中英导航切换后仍称“开发 / Dev”；正文中文范围如实提示。旧任务草稿先导出备份，再验收保存、导入、导出。
7. Git diff 中游戏文件、字体、历史任务状态和原 CSS 不应改变。确认后由维护者推送，记录真实提交和 Pages 结果。

安装回退使用更新器打印的实际备份路径，先 `--rollback 备份 --check`，再 `--apply`。回退检测后续编辑，绝不使用 force。
