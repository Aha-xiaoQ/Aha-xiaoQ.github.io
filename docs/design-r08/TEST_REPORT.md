## 复现与修复

本轮在 Linux 构造真实悬空目录链接：existsSync 返回 false，lstat 确认目录项是链接，旧构建器 safe() 仍返回了路径。原始结果见 validation/r07-defect-reproduction.json。R08 直接 lstat 工作区根、祖先与相对路径各段；只允许真正 ENOENT 缺失，其他错误关闭授权。安装器、作品集合构建器、开发栏目构建器共用同一个模块。
