# 本轮图形来源与职责

`assets/illustrations/controller.svg`、`web-studio.svg`、`workflow.svg`、`experiment.svg` 为本轮自行编写的 SVG 几何组件；没有复制参考网站的图片或个人标识，没有远程资源、脚本或外部字体。配图表达作品类别，不是作品运行截图。

控制器保留游戏的直觉辨识；浏览器窗口表达网站；任务清单→编辑器→检查表达开发工具。用相同的线宽、米白轮廓、红色底板与留白形成统一风格，而非强迫不同内容都使用一个抽象方框。

素材显示由稳定内容 ID 或内容类别关联，不能按数组下标随机分配。工作流上方的“开发工具”是用途分类；原有“开源”标签保留，不改变或扩大许可。原站的 LICENSE、RIGHTS.md、Q咪和游戏素材声明不修改。

包内截图只是离线组件预览。游戏海报来自用户截图的局部裁片；猫精灵使用明确写 TEST 的诊断图。它们不放入源码 payload，也不能当作原站完整素材验收。预览使用的私有字体不进入交付包。
