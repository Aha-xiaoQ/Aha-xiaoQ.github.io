# R08 发布验收

记录候选 commit、OS、Node 版本和浏览器，附命令原始日志。不要只写“看起来正常”。

1. 先运行 test:security、test:r07、test:r08；Windows 主机上尤其核对悬空目录/junction 必跑测试。文件符号链接若 skip，记录权限原因，不能算已通过。
2. site:build、journal:build、site:check、journal:check；原 npm run check 和 npm test。
3. 游戏桌面每条独占一行，封面完整；820/768/390/320px 检查内部换列，筛选只剩一项仍全行，不丢试玩/介绍/视频/下载按钮。
4. 项目页工作流“开发工具”与图形可辨，“开源”保留为属性；开发页网站能识别为网页，手柄下方没有细小标语。真实 Q咪精灵表保持可用。
5. 首页→项目→游戏→开发→项目子页→前进/后退；检查原动画、主题、语言和浏览器缓存。减少动态效果、键盘焦点、200% 文本放大。
6. 确认旧草稿、原任务和 game 工程未重置；检查 Diff 后手动推送。

Linux 本地通过不代替 Windows，离线布局截图不代替完整站点 HTTP/资源/转场。新增工作流配置不是已经在 GitHub 运行的结果。
