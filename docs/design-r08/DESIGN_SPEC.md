# R08 设计规则

## 保留
黑、米白、红色的既有视觉体系；主站首页、标题区、字体选择、六项导航与原转场。装饰服务于内容，不增加第二个后台风格。

## 游戏列表
每个条目独占一行。桌面左侧 46% 为完整封面，右侧为分类、名称、简介、主要操作和必要设备提示。图片窗口为 16:9，不裁掉海报标题。820px 以下卡片内上下排列；列表仍只有一个条目一行。筛选不会把卡片变成另一种大小。按钮区自然换行，不截断完整介绍。

## 项目分类与配图
第一标签回答“这是什么”，而不是“许可证是什么”。工作流为开发工具，“开源”保留在属性行。项目内容仍由 site-data.js 提供；presentation.json 只补表现分类，不复制标题与事实。

workflow.svg 是任务清单、代码和检查流程的抽象示意，不是实际软件界面截图。web-studio.svg 是带浏览器栏、页面布局和指针的网页符号，不宣称展示真实站点数据。controller.svg 保留手柄语义。experiment.svg 支持后续实验项目。

开发卡片不再出现 IDEAS INTO REALITY 小标语：类别、标题与摘要已经足够解释。图片文字只保留可辨认的大类别词，细小说明在正文而不是烘焙进图。

## 内容层级
项目概览解释用途与体验入口，任务和技术细节进入子页面，导入导出留在管理页。既有任务事实与阶段不因为 UI 变好就标成完成。不为美观虚构精选、合作人数、星标数或发布状态。
