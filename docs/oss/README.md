# Source distribution status / 源码分发状态

游戏混合源码包已撤下，暂不重新发布。此目录保存网站运行文件、在线试玩和普通离线游戏下载；浏览器收到的 HTML、JavaScript 仍可读取，不是加密或隐藏源码的方案。

角色、地图、美术、音乐及部分混合实现尚无完整授权证据。当前保留现有试玩，这部分仍列为未解决风险，并排除在本站原创源码授权之外。版权声明不等于授权，公开可下载也不等于可以自由再分发。

既有原创与第三方许可继续按各自范围有效，未被撤销或扩大。历史清单只证明所记录版本的范围，不能据此宣称当前整站或整款游戏均已清权。

Mixed game source packages are withdrawn and are not being republished. This tree supplies the static website, playable HTML/JavaScript and ordinary offline games. Browser-delivered code remains inspectable. Retained game media and mixed implementations have unresolved rights questions; they receive no new original-code licence. Existing scoped grants and upstream notices remain effective.
