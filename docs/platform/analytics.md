# 访问统计与本人排除

[English](analytics.en.md)

本文说明本人排除设置的规则和维护边界。实现审阅基线：`8735b6bffa39dcbd1cc635bd897ec59dfc7ef839`。对应实现是 `assets/site-analytics.js`，回归为 `tests/analytics/privacy.test.mjs`。

## 访客可以设置什么

共享页脚提供“本浏览器本人访问不计入”按钮，`aria-pressed` 与可见状态说明开启/关闭。默认不排除，浏览页面或展开说明不会保存本人偏好。只有主动点击才写入同源 `localStorage` 中的 `xiaoq-stats-owner-excluded=1`；撤销时删除该键。它只是一个布尔选择，不包含账号、设备标识、IP、UA、访问路径或身份推断。不同浏览器、配置文件和来源分别设置；清理站点存储后需重新开启。

保存成功后，点击触发页面刷新，让聚合统计和既有 Cloudflare beacon 的初始加载器共同遵守偏好。此前已上报的访问无法撤回。其他已打开的同源标签页收到存储事件后更新开关，并在后续聚合页面访问事件中遵守新偏好；不会强行刷新这些标签页。它们已载入的独立 beacon 需刷新后才能遵守初始加载排除规则。不能通过移除 script 宣称停止已执行的脚本。

存储不可用时，按钮只在当前文档内保留排除选择，暂停后续聚合上报，明确显示不能持久保存。已载入的独立统计不受这次内存选择可靠控制；使用页脚“用不计入链接重新打开”链接，让 `stats=off` 在新文档初始化时排除两个加载器。这个链接保留当前路径、其他查询参数与锚点，只用于同源导航，不发送为统计数据。

## QA 兼容与计数语义

- `?stats=off` 延续原来的标签页内 QA 排除。能够使用 `sessionStorage` 时，随后路由和刷新仍排除；存储不可用时，当前文档内仍排除，重开链接必须保留参数。
- `?stats=on` 只撤销 QA 排除，不能覆盖本人偏好或 `__XIAOQ_ANALYTICS_DISABLED__`。关闭本人排除也不撤销 QA 排除。
- 聚合 POST 仅在正式 HTTPS 域名、顶层页面且没有排除时发送，负载仍只有规范化 `path` 和 `visitStart`。不发送查询、锚点、来源页面或访客 ID，继续 `credentials: omit`、`referrerPolicy: no-referrer`。
- **PV** 仍是页面访问次数。同一文档的连续同路径事件、语言/查询/锚点切换、`/index.html` 别名和重复初始化不重复计入；A → B → A 分别计入。真正刷新可以新增 PV。
- **visits** 仍由标签页 `sessionStorage` 最近一次计入 PV 的时间计算：空会话或间隔至少 30 分钟时 `visitStart=true`，近期连续计入时为 false。重复路由事件不续期；排除期间不更新时间。存储不可用时使用 null，保留覆盖未知状态。正常新标签页的空会话开始新窗口；由 opener 复制会话存储的标签页/复制标签页可能继承原时间，这是现有语义的限制。

visits 不能称为 UV、独立人数或确认真人。本人开关只是主动排除当前浏览器，不能识别别人是否为本人；没有机器人识别依据，本轮没有添加短停留等启发式过滤。unknown 与 404 未归类规则不变；历史计数不能追溯分辨人类，也不补扣过去访问。

## 维护与验收边界

`SITE_ANALYTICS.getState()` 提供当前排除状态，`setOwnerExcluded(boolean)` 只设置偏好和更新控件，不主动伪造 PV 或刷新；页脚的主动点击在持久保存成功后才刷新。单一初始化守卫、成功路由事件和路径去重继续是上报入口。新检查纳入 `npm run test:analytics` 与 `npm test`。

本轮不修改后端数据库、schema、secret、旧统计、审核或权限。网络传输和既有服务的处理规则不因前端负载精简而消失；这里没有新增 IP/UA 持久记录，也不承诺服务端没有自己的日志。前端去重无法保证后端所有并发请求去重或识别人类；涉及服务端幂等键或新 schema 的方案应另行提出。

本地浏览器只访问独立临时配置中的回环发布产物；不访问正式主站制造测试流量。统计说明采用“本人可主动排除；重复前端事件不重复计 PV；其余统计口径保持原样”，并记录生效版本。后续计数可能因主动排除而减少，不能据此解读为真人比例提高。
