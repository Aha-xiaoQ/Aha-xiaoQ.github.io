## 新增框架检查的实质内容

数据与扩展：项目唯一 ID、安全路径/URL、日期、任务状态、完成证据、任务依赖与循环、状态源隔离；仅修改登记数据即可创建第三个测试项目，依次验证 draft 不公开、public 生成独立页面、archived 保留历史，再转 draft 只移除本工具拥有且未被手改的页面。测试项目不在交付的公开索引中。

结构与集成：通用渲染器不写死混合马里奥；项目级路径、旧别名、六项主导航、单一页头/页脚、原路由转场定义及唯一调用；保留原有 `SITE_DATA.notes`；冻结的原站 `SITE_EN` 词典不被修改；构建幂等与人工改动保护。

公开任务：每页最多六项；搜索、状态、翻页、键盘展开验收详情；跨项目不串任务；URL 筛选恢复及无查询参数返回时清理旧筛选。公开页读取共享文件，不把未发布本地草稿冒充团队状态。

旧编辑器：native-B 离线测试加载原配置、模型、快照、界面工厂与原管理组件，确认未保存的负责人输入在跨项目往返后保留；保存草稿仍使用 `xiaoq.collab.r01.draft`；原导出保留修改后的负责人。这里的存储与下载是测试替身，不能证明浏览器刷新后的持久化或原生文件下载已验收。新项目只有 JSON 文件维护与导出，本轮没有交付新的多项目网页编辑后台。

更新保护：干运行不写入、四组重复应用、逐字节回退、原状态/样式保护；核心冲突、同名新文件、两个状态源、检查后再编辑、回退前新增编辑、符号链接、路径穿越及字体/二进制路径拒绝。校验也拒绝未登记的额外 payload 文件。校验值用于损坏检查，不是数字签名或完整安全审计。

HTTP：分别请求目录、两个项目路径、任务页、模块 JS MIME、目录 JSON、状态 JSON；POST 返回 405。服务器只更改入口提示文字，不改其请求处理逻辑。
