# 参考研究与应用

核对日期：2026-09-15。这里只记录阅读到的结构经验，不导入上游视觉素材、代码或品牌。

## Blender Developer Documentation

官方入口将入门手册、功能/模块资料、版本说明分别组织。模块页说明职责、负责人和沟通；贡献指南强调聚焦的改动及审核过程。本轮借鉴“项目→当前范围→入门/资料/贡献”结构，不复制复杂组织层级或页面外观。

- https://developer.blender.org/docs/
- https://developer.blender.org/docs/handbook/organization/modules/
- https://developer.blender.org/docs/handbook/contributing/

## GOV.UK Design System — Navigate a service

官方模式说明整体网站和具体服务的导航要有清楚层次；导航不应变成完整站点地图。本轮据此保留主站六项导航，将项目内导航放入内容层，维护入口不占顶栏。

- https://design-system.service.gov.uk/patterns/navigate-a-service/

## 研究如何影响本轮

采用层级、职责、贡献入口与渐进披露，不换用第三方设计系统；主站颜色/字体/卡片和路由仍为唯一视觉与动画来源。没有把“知名项目采用某做法”当作适合所有场景的证明，也没有用它证明我们的实现已通过测试。
