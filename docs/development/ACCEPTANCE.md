# 完整仓库的人工验收清单

这份清单不因为生成更新包而自动通过。请记录日期、系统、浏览器和实际结果。

## 页面与原站

首页 → 开发日志 → 混合马里奥概览 → 任务 → 资料详情 → 返回；再进入网站项目。浏览器前进/后退、直接刷新、新标签打开和旧 dev 地址均应可用。导航只有六项，子页高亮开发日志；页头/页脚各一套。原游戏列表和介绍、试玩与下载继续正常。

检查真实霞鹜文楷、Logo、背景、缓存、ESM 与 CSP 加载；不能用回退字体截图作为最终验收。动画跟随原路由；系统减少动态效果生效；快速连续切换不能留下旧页覆盖新页。

## 内容与信息

首页不是马里奥独占页面；只出现真实项目。原笔记不丢；任务不是产品完成率；网站 R04 待验收与游戏阶段分开。无任务/搜索为空/读取失败有不同说明。长标题、很长的资料链接在窄屏不溢出。

## 任务与草稿

跨项目搜索/过滤/分页不串号。展开原记录工具，编辑并保存/导出；离开项目后返回；刷新恢复原工具草稿。公开列表仍显示仓库共享状态，不暗中把个人草稿发布出去。下载/导入为浏览器本地操作，需人工校验提交。

## 可访问性

320、390、768、1440 像素宽度；键盘逐项到达主导航、项目卡片、筛选、分页、详情和返回链接。焦点可见；详情可开关；无颜色单独传达状态。英文开关正常，中文项目正文有语言提示，不称全站新内容已英译。

## 发布记录

记录检查命令、结果、待修项、实际 commit、Pages 链接与部署结果。存在阻塞缺陷时保持本地待验收。原游戏的通关、物理手感、手柄、触屏、音频不在本轮页面测试中冒报通过。
