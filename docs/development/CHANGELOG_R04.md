# R04 变更清单

页面：开发日志改为多项目目录；项目概览、任务、资料详情、更新、参与、交接统一按稳定 ID 组织。新增网站项目与独立任务；混合马里奥读取旧状态。公用介绍面向观众，维护信息下沉，任务每页六项。

工程：新增纯数据校验、通用 renderer/runtime、局部 CSS、JSON 注册表、构建器、默认 draft 脚手架、测试与安全升级工具。原生 shell/router 在经过核对的基线上改为通用接入，原转场函数/时长不另造。

数据：不覆盖原任务、生成状态、草稿键和历史交接。安装时输出当前来源与保护哈希。旧 UI 单项目断言显式被本轮集成契约替代，数据模型与旧更新器回归保留。

交接：增加 START_HERE、HANDOFF、设计规范、架构、数据契约、参考研究、决策、路线、验收、安装/回退和真实测试报告。历史包的重要说明另放在更新包 history 供参考，不自动覆盖用户仓库历史。

边界：不换主站主题，不增加第七个导航，不改游戏运行/资源/下载，不改变许可，不提交/推送、不自动关闭 Issue。
