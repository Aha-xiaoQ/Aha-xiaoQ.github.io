# 发布检查清单

自动：terra:verify → journal:build → site:build → release:preflight → 原check/test。当前版本、源码ZIP、候选SHA、任务投影、三个资料入口和历史折叠应一致。

人工：先在Windows完整副本验证所有命令和junction；用真实HTTP检查首页→开发→项目→当前源码→下载，刷新/前进/后退/中文英文/320px/200%缩放/剪贴板拒绝。确认主站风格、图标、动画没有退步。

游戏：全新配置、改键、手册开关、已暂停/游戏中/离开标签页/返回历史缓存、实体手柄与触屏、按住键退出菜单、存储禁用及刷新、全屏、音频听感、自然地表和隐藏关通关。

已通过自动检查不等于允许发布。天然流程或设备项未通过时保留待验收；RELEASE_REVIEW绑定准确候选SHA并由维护者审阅。协议原型不当正式1-4宣传。不用“精品”“顶级”或测试总数代替验收证据。
