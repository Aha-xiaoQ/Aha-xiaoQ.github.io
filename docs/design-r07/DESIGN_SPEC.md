# R07 组件与场景规范

## 布局
游戏和项目集合：大于 680 CSS px 统一双列，680 px 及以下统一单列。奇数项的最后一项保持半宽，不跨列；筛选剩一项也不放大。排序不影响卡片面积，第一项不等于精选。工具保持统一横向卡（小屏纵向），因为可读的界面示意比列表密度更重要。未来需要精选时，放在有清晰标题的独立区，不向普通列表混入隐含特例。

卡片媒体窗口均为 16:9，正文水平，四边留白采用 8/16/24/32 px 阶梯。同一行内容不同可自然增高，不裁掉正文来伪造整齐。动作组贴近底部，主要动作只有一个。封面与纯角色的主体占比不同，但窗口和对齐规则相同。

## 视觉
主题颜色继承原站 --paper/--bg/--surface/--accent/--muted/--line。红色只作交互强调、细阴影与局部标识。不得重新画首页或页头，不添加额外导航动效。装饰不可横穿主体。角色场景留大块低纹理区域，工程线稿仅用于没有照片/封面的技术作品；已完成的游戏海报不得再盖斜纹或文字。

六种预设：character-paper、character-night、poster、interface、blueprint、pixel-window。它们是可直接运行的 CSS 场景，不是重新生成的游戏背景图。不允许根据数组索引随机分配背景。Q咪默认 warm-paper，对应 character-paper；不加反衬白纸片、黄框或色键处理，不把柔和插画强制 pixelated。

## 可读性与可达性
链接保留真实 href，原生键盘焦点明确，图片失败仍保留标题、介绍和入口。列表有集合语义，卡片没有链接嵌套。无脚本时静态作品列表仍能阅读与进入；筛选需要脚本，不能宣称完全无脚本交互。减少动态效果时精灵动画与悬浮阴影关闭。长中文、英文、文本放大和窄屏均需实测，自动测试不等于 WCAG 认证。
