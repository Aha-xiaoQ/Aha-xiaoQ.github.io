# 兼容边界

本包基于当前会话已发出的 R06 源码。兼容由 native/clarity 与 A/B 形成的四种状态历史，前提是已安装 R06。R06 之后的手工脚本编辑不能通过猜测覆盖：核心文件和已登记生成页不一致时停止，提供冲突路径。

payload 中包含两份未改动的 journal 模型/渲染依赖，供安装器离线生成页面；与目标一致时不写入。它们不是新的状态源或第二套模板。原共享 CSS、router、项目 JSON、旧交接、R05 包、游戏运行文件、字体和下载包不在改写范围。

首次安装会重建 projects/games/tools 的 main；主页和其他原生外层页面只追加公共依赖，正文不替换。执行旧 R06 安装器回退 R07 是错误操作；应使用本包记录的独立备份。
