# 参考与采用范围

读取日期：2026-09-15。以下是本轮工程选择的参考，不是复制上游品牌或保证质量的背书。

- Scottish Government Design System, Card navigation: https://designsystem.gov.scot/patterns/navigational-pages/card-navigation 。采用一致图像比例和清晰摘要/目的地的原则；本项目根据现有宽度使用两列，不照搬其列数。
- Card: https://designsystem.gov.scot/components/card 。采用动作位于卡片底部的组织方式。游戏有多个操作，因此不把整张卡做成嵌套点击区域。
- Images: https://designsystem.gov.scot/styles/images 。信息不能只靠图片；图片尺寸/加载策略独立检查。本轮没有压缩媒体或虚构 srcset 派生资源。

含文字的游戏海报使用 contain 是针对现有素材的决策，不等同于参考站所有 aspect-box 的裁切行为。角色、截图、海报用途不同，统一的是设计体系，不是强迫使用同一种背景。
