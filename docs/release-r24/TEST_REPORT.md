## 本轮发现并修复

原公开管理入口与工程文件链接进入网站；旧任务沿用0.4.1与1-4待转录说明；首页最近作品过时；静态/动态内容与懒加载的缓存身份缺少统一发布绑定。现增加公开投影与确定产物版本，保留源工程和原始状态。

新增核验期间修正了自身三处问题并补回归：管理模块裁剪曾对二进制文件进行文本转换，现严格限定两份JS；外部Issue的编码查询参数被误判为路径，现只校验路径部分；同一模块重复转换现保持幂等。截图测试恢复全新页面状态后重截，不含合成的复制失败或选中文本演示。
