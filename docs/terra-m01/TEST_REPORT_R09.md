## 什么已经模块化，什么还没有

8 个 ES 模块在候选游戏中实际调用；测试不是只测未接入的演示模块。33 个 compat 文件是按职责划分的原闭包片段，依旧有原共享状态和 wrapper 顺序，明确是迁移区，不称作独立模块。资源从源码中拆出，构建时为兼容重新内嵌；未声称下载更小、流式加载或完整离线。

## 浏览器测试边界

真实 file 导航返回 ERR_BLOCKED_BY_ADMINISTRATOR，未更改或绕过浏览器策略。游戏使用 set_content 执行完整候选单 HTML，保留原 CSP，设置固定随机源和测试标记，阻止所有远程请求。隐藏场景通过真实管道状态机进入，但用了测试接口放置人物、设置召唤条件与伤害；不是自然完整通关。HTTP/ESM 网络加载尚未验证。独立 Node HTTP 请求测试并不能替代浏览器端到端。

开发资料页采用原 R08 原生模板与样式文本，在静态 fixture 中检验结构、链接和宽度。页头图片、Logo 文件、霞鹜文楷及真实页面转场未包含在此预览中。没有复制任何字体文件到包内。

## 最终 ZIP 的复核

外层压缩后会另行解压，校验每个 SHA256SUMS、payload 清单和 ZIP CRC，再复跑 18 项安装器测试，并在解压包新建的 R08 夹具上安装→工程测试/构建→主站生成检查→重复安装→逐字节回退。精确最终 ZIP 校验值和最后执行结果另存同名 FinalVerification.json，避免将 ZIP 自身哈希写进 ZIP 形成循环。validation/ 保留本次预打包实际日志和源包解压记录。
