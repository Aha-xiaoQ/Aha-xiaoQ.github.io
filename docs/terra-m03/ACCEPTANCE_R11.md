# 发布者验收

- 在备份/分支内应用，运行 terra:verify、terra:level:check、journal:build、原check/test。
- 原网站导航/样式/转场与游戏入口不变；源码页和新接入指南可达，下载文件SHA与元数据一致。
- 解压网站下载的M03ZIP，verify/level:new/level:check/dev成功；新图可在完整候选中运行。
- 开发章节样例不作为正式城堡发布；默认draft，原第三期仍是主线。
- 自建图的跳跃/攻击/检查点死亡/门往返/设置暂停/结算/返回原关人工跑完。
- Windows、真实HTTP/ESM、手柄、音频、自然通关、素材来源逐项验收；CI配置不是CI已执行。
- 源码有后续改动时不重装旧包；用Git审阅diff再提交与推送。
