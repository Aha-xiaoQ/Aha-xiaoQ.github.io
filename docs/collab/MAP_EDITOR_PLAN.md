# 可视化地图工坊：研究与实施计划

日期：2026-09-19。状态：核心编辑闭环已实现，自动验证通过，真实浏览器验收待完成。用户最新优先级：先完成可自由编辑地块的地图编辑器，参考成熟项目，先规划后编写代码。已新增地图工坊与地图册入口；现有游戏本体未修改。

## 目标与使用路径

零基础用户打开网页 → 从空白或现有地图创建自己的副本 → 绘制地形、调整对象 → 保存 → 导出 → 重新导入继续编辑。开发者在相同数据上接入角色与机制。首版不是通用游戏引擎，也不承诺现有全部地图已经可通关。

## 参考与取舍

- Tiled 的地块编辑：画笔、橡皮、矩形填充、桶填充、选择、图块复用。采用熟悉的操作；复杂地形规则不作为第一步。
  https://docs.mapeditor.org/en/stable/manual/editing-tile-layers/
- Tiled 的对象编辑：位置、尺寸、自定义属性、对象关联。管道、出生点、奖励与机关是对象，不应压成仅有颜色的格子。
  https://docs.mapeditor.org/en/stable/manual/objects/
- LDtk 的图层与实例：图层决定可放置的内容；模板定义与场景实例分开。
  https://ldtk.io/docs/general/editor-components/
- LDtk 自动图层：地形数据驱动贴图，避免更换外观同时改变碰撞。首版采用简单确定性边缘拼接，规则编辑器后续再做。
  https://ldtk.io/docs/general/auto-layers/

借鉴交互和数据组织，不复制品牌、代码或未核对许可的素材。内嵌 Tiled/LDtk 不作为首选：本项目需要浏览器免安装、中文引导和专用运行接口；通过受限 Tiled 导出保留专业工具衔接。

## 界面与视图

保留 atlas 的深色、米白、红色强调和现有字号体系。画布占主区域，缩短现有介绍区。

- 顶部：地图名称、打开、新建、撤销/重做、保存状态、导出。
- 左侧：图层及对应素材。地形、装饰、对象、隐藏内容、参考信息各自可见/锁定。
- 中间：可缩放与平移的网格画布、鼠标位置和笔刷预览；工具栏始终可见。
- 右侧：当前选中对象的中文属性；无选中时显示简短操作说明。
- 底部：地图尺寸、问题定位、当前编辑层。高级数据折叠，不让新人先面对 JSON。
- 小屏：折叠两侧面板，触屏绘制和平移明确切换；精细编辑优先桌面，不能假称手机与鼠标同等高效。

三视图共用同一份地图，不保存三份独立坐标：结构图、效果预览、秘密与路线。普通效果预览不泄露隐藏物体；隐藏层以虚线/半透明呈现奖励和触发条件。未核验的参考记录显示待核验，不生成虚假的原版结论。原版截图对照需后续有来源的素材支持。

## 数据与程序结构

1. 新建独立带版本号的编辑工程格式，地图/房间/对象采用稳定 ID。原始参考文件只读，编辑保存为个人工程。
2. 地块层使用格子坐标；对象层保留像素坐标、尺寸、运动范围、奖励、关联 ID。导入不把非整格对象强制吸附。
3. 导入适配器保留 W02 的 source、markers、topology、provenance 和未知扩展字段。不能编辑的机制保留并锁定，界面说明原因；不得静默丢弃。
4. 文档状态、编辑命令、渲染器、存储、导入导出、校验与运行适配器分模块。所有编辑动作走统一命令，拖动一次对应一次撤销。
5. 结构图与效果图只是渲染器；换视图不改地图。贴图注册表独立于碰撞类型，并记录素材来源。
6. 保存使用浏览器本地存储并提供明确的导出备份；失败、容量不足、格式不兼容时提示，不虚报保存成功。不要求账号，不自动上传，不执行导入文件中的代码。
7. 现有 Tiled 导出仅是对象层，不宣称可回写。先保证本工具工程格式无损往返；Tiled 互通限定到实测支持字段。
8. 运行导出使用现有 map.json / stage.json 接口，先校验支持能力；不能仅将编辑工程改扩展名称为可运行地图。水下、循环机关和完整敌人行为仍由对应驱动负责。

## 实施顺序和验收

### A：编辑闭环（当前优先）

- 空白地图及现有底图副本，选择区域，地图尺寸调整。
- 连续画笔、擦除、矩形填充、桶填充、吸管。
- 框选、移动、复制粘贴、删除；图层显隐和锁定。
- 平移、缩放、网格吸附、撤销与重做。
- 自动保存、文件导出、再次导入；切图不会丢失未保存内容。

验收：无需命令行创建一张有地面、平台和缺口的地图；连续快速绘制不漏格；一次笔画一次撤销；刷新恢复；导出再导入内容一致；缩小地图明确预告越界数据，取消时完全不变；32 关参考数据导入不会修改源文件。

### B：三视图与对象

- 基础地形效果绘制、原始结构对照、可开关隐藏标记。
- 出生点、金币、奖励块、敌人位置、管道入口的中文属性。
- 区域关联跳转、奖励清单、关卡特色摘要；显示未实现能力。

验收：三视图位置一致；隐藏内容仅在相应开关开启时显示；对象移动同步其关联数据；不把敌人位置展示称为敌人行为实现。

### C：开发接入

- 按支持能力导出开发工程、检查报告和操作说明。
- 将基础地形送入独立实验预览，保持线上三期游戏不变。
- 验证导出地图在实验运行时中碰撞、出生点与编辑画面一致。

多人参与先通过工程文件交换；实时协同、脚本编辑、完整机关驱动不混入首版。

## 验证策略

模型测试覆盖：连续笔画插值、填充边界、撤销往返、图层锁定、尺寸裁剪、未知字段保留、重复 ID、超大/损坏文件、关联目标缺失。跨 32 关与全部分区做导入/导出回归。

浏览器验收覆盖：打开→绘制→撤销→保存→刷新→导入→切换地图；键鼠、触屏取消、快捷键不影响输入框；桌面与窄屏截图。浏览器连接不可用时不宣布视觉或交互验收通过。
