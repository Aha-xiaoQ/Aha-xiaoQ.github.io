# 设计决策记录

## ADR-001 · 保留笔记，新增独立开发中心（2026-09-14）

原因：笔记页仍有明确用途，旧站已有路由与多语言逻辑。独立 `/dev/` 更容易隔离状态管理，不需要重做整个网站。结果：笔记、游戏列表、三期介绍中加入口；不删除旧页，不改旧游戏入口。

## ADR-002 · 先零依赖工具，不换引擎

原因：本轮目标是能启动、能贡献、能恢复，不是玩法重写。使用 Node 标准库完成静态预览与检查。Vite/TypeScript 与统一游戏构建仍是后续选择，不把迁移工作夹在协作配置里。

## ADR-003 · 状态源唯一，网页草稿不伪装成后台

`collab/project.json` 是共享状态。静态网页携带生成快照；本地编辑导出后经维护者校验提交才共享。旧草稿与源状态不匹配时不自动覆盖。暂不连接实时 GitHub Projects/Issues API。

## ADR-004 · 安全增量交付优先于巨型全仓 ZIP

整仓下载在制作环境不可用，且不应重复分发原作资源、下载档案和字体。通过只读连接读取受影响原文件并校验其 Git blob。交付显式清单与前后哈希，只覆盖这轮变更；基线变化即停止。

## ADR-005 · 不改原许可和线上设置

新增协作代码使用独立限定许可，现有游戏仍按原许可与权利说明。CI 模板只是文件交付，不代表实际执行。分支保护和审批需由用户在推送后设置；不自动给外部贡献者写权限。

## 2026-09-19 地图工坊音频
场景音乐按 Underwater / Underworld / Castle / Overworld 显式分类，星星效果优先；预览和离线包共用 audioFiles 与 themeFor，避免两套音频配置漂移。新增录音沿用既有固定上游版本，来源单独记录，不改变原始游戏脚本。

## 2026-09-19 · 连续版与单图导出共用运行器
连续版使用 campaign-build/campaign-ui，沿用 editor-play 和现有地图与美术声音资源，保留单图导出。关卡通关回调携带生命、金币、分数及形态；开屏自由选关开启新局。参考终点转换仅发生于构建的文档副本。7-2 原始来源缺失最终横管 transport，连续版明确连接到 area-2 既有出生点，不改写参考源。基础游泳只启用于 Mario 试玩，开发包通用运行器仍拦截未支持的水下驱动。此版本标为测试版，不声明原版完全一致。
