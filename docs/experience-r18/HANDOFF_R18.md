# R18 交接

基础：R17 Interaction Polish；游戏 0.4.2 / M06 未改。网站工作范围：搜索、开发筛选地址状态、资料目录、历史滚动/焦点、异步失败恢复。

本包是增量安装，不替换整站。先读取本目录 START_HERE、测试报告和 ACCEPTANCE。游戏玩法/地图/素材/任务及下载均不在此次修改范围。

维护规则：
- 搜索索引由 content/site-data.js 和已登记公开项目资料生成。不要手编第二份内容目录，不将内部任务或历史资料混进默认搜索。
- 查询状态保存在 URL，不保存搜索历史到 localStorage。浏览器 URL 仍可能被已有日志记录，不能宣传全站零收集。
- 一个路由器管理转场。不要在新组件增加点击代理或重写 history 全局方法。
- 原始 CSS 转场定义、主站配色、小图标原样保留；新工具样式局部生效。
- 图片/字体不在本轮包内。本轮预览是系统字体与真实组件代码的离线布局。
- 当前搜索标题与 UI 主要中文；页眉辅助名称随现有语言设置显示 Search，完整搜索界面的双语内容留待后续编辑。

下一步先完成实机验收，再按真实访客反馈调整索引关键词、页长与搜索位置。不要在发布前增加自动账号、云端搜索、后台同步等新范围。
