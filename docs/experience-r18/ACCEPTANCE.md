# 发布前实机验收

本地自动化通过后，在完整 R17 网站副本应用 R18。

## 必验路径

1. 首页、游戏、项目、工具、开发、关于均能看到同位置搜索入口；原六项导航、小图标及游戏单条布局不变。中文与英文切换不挤出导航；搜索内容正文目前以中文为主。
2. 搜索“泰拉”“源码”“工具”，更改类别、翻页、清除。复制搜索地址到新标签再打开，输入和结果应一致。索引不可用时重试可恢复，且仍可进入四个主要栏目。
3. 开发页输入关键词、选类别，进入项目，再后退：关键词、列表及滚动位置保持。长资料进入另一篇再后退，焦点不能跑到主导航。快速连续点击以最后一次为准。
4. 长资料展开目录、用键盘选章节；直接访问带锚点地址。原源码下载、命令复制、三个主要资料入口、历史折叠与任务流程保留。
5. 飞行模式/断网/慢网下尝试打开项目，旧内容不消失；恢复网络后点击重试。不应自动无限重试或刷新。测试返回/前进、真正 BFCache 及刷新恢复。
6. 在320、390、768及常用桌面宽度检查；200%文本放大、屏幕阅读器、触屏、系统减少动态效果和强制颜色需实际核对。
7. Windows 上执行 Node 检查和安装/回退，特别是悬空链接与目录 junction。检查 Git diff 后提交，部署后再核对真实字体、图片、CSP、资源模块和源包下载。

通过与否记录在发布系统或仓库 Issue 中。此文件没有替维护者填写任何发布批准。
