## 检查中修正

1. 新测试把`<i`误配到`<img>`，改为匹配完整i标签；源图片保护断言保留。
2. 源码状态“待验收”位于页面元数据与页头，测试同时检查元数据与内容，不删状态要求。
3. 初稿安装器错误假定路由有写死的r16导入。实际原路由通过assetHref继承脚本查询号，现只核对真实加载锚点，路由源文件完全保留。
4. 旧卡片测试要求5个链接，其中一个是重复标题链接；按本轮明确设计改为4个不同动作，仍逐项校验所有目标。
