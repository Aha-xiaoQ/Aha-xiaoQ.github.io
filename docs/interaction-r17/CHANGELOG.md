# R17 变更

## 访客可见

开发项目卡片不再附带红色箭头方块，改为明确的“查看项目”入口，名称进入可访问标签。小手柄和小浏览器图标保持 96×72，颜色、位置和 SVG 源文件不变。

资料与快捷入口：一个目标一个原生链接，整个单目标卡片可用键盘进入；不再同时给标题与“阅读”放重复链接。卡片仍有下划线提示，不能只靠悬停判断可点击。

作品卡片：移除重复标题链接，保留独立的操作区，卡片正文可选择。游戏仍一条一款；试玩、介绍、视频、下载四项保留，试玩优先，视频/下载次要。不把多目标卡片整体绑定到某个入口。

首页只去除快捷入口和重点入口的箭头节点，其余艺术、时钟、文案与布局原样保留。页脚去除 ↗。外部新标签使用文字提示和 noopener/noreferrer，下载保留原生 download 与 ZIP 格式标记。

## 工程

增加 assets/ui/site-actions.js 与 .css，静态生成和浏览器渲染共用同一链接契约。不安装 UI 库，不增加路由，不附加全局 DOM 扫描器或转发点击事件。

新增 ui:check / test:ui；静态构建器统一处理旧 HTML 的明确箭头节点与脚本加载顺序。缓存号更新是加载本轮文件所需，并非重画整个网站。

## 明确保留

游戏0.4.2/M06源码、packages、downloads、任务数据、版本/更新/许可信息、六项导航、游戏单行布局、R12图标、主站共享主题样式与路由动画均不改。原生路由源码不变，外层HTML的路由脚本查询号用于既有journal加载链。
