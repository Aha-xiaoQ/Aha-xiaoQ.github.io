# 发布前验收

## 在完整网站执行

1. 先备份本地修改，应用包后运行ui:check、test:ui、journal:build、site:build、release:preflight与原check/test。
2. 首页→游戏→介绍→开发→项目→资料→源码。直接打开每个URL、刷新、后退和前进，确认均使用同一主站外壳，未出现旧箭头或重复组件。
3. 游戏每条有试玩/介绍/视频/下载四项；资料单目标卡片只有一个Tab停靠；多操作卡片的正文可以选择，不因点击空白而意外跳转。
4. Tab与Shift+Tab顺序可预测，Enter按链接原生运行；浅色卡片焦点可见。Ctrl/Command点击、中键与右键正常。注意真正执行下载而不是只检查download属性。
5. 320/390/768/1440px、200%文字缩放；触屏无依赖悬停的按钮；减少动态效果与系统强制色彩下仍可识别操作。正文中的流程箭头和code例子保留。
6. 中英文当前按钮、复制、筛选/分页/历史折叠保持可用；素材、任务状态、当前0.4.2下载与未验收标识不变。
7. 记录真实Windows、浏览器、页面URL与Git提交号，再人工推送。此包没有运行远端CI、发布或替代人工审批。

## 拒绝发布条件

安装冲突/未知核心文件；新版生成页面不一致；试玩或下载目标变更；源码/任务被改写；主题或转场退化；窄屏溢出；键盘无法到达入口。发生冲突不通过倒退旧文件来绕过保护。
