# 链接与视觉层级决策

## 1. 少一个符号，不能少一个线索

重复箭头不替换为另一批图标。站内跳转用明确文字、边框或下划线；鼠标悬停、键盘焦点与触屏静态状态都要能识别。图片、标题、简介先服务内容，行动入口集中在固定区域。

## 2. 两类卡片，不用一套点击逻辑强套

资料卡只指向一个目标：整张卡片只有一个真实 a，内部不嵌套按钮。作品/游戏卡可能包含试玩、视频和下载：卡片本体不绑定点击，分别提供原生链接。标题不再重复同一目标，避免重复 Tab 停靠与视觉噪声。

## 3. 主次而不是全都高亮

列表每卡最多一个主要行动。试玩使用米白底和小红色错位阴影；介绍采用细边框；视频、下载采用文字层级。项目卡入口为克制的描边按钮，不使用占据半个卡片的大色块。单目标资料卡仅给底部文字一个细下划线，不堆叠第二个按钮框。

## 4. 主题保留，手感克制

颜色、WenKai、红黑米白、像素艺术、标题斜面、全站转场沿用原站。此次140ms只用于控件颜色、边框和阴影，不移动卡片文本，也不让页面布局抖动。仅精确指针/可悬停设备启用 hover 增强；减少动态效果关闭本轮控件过渡。

## 5. 语义保持

导航用 a，筛选/复制/展开用 button 或 details。保留 href、下载、新标签、Ctrl/Command点击、中键和原生右键。不用 onclick 假装链接。新标签意图靠文字说明，不增加箭头图标。

## 6. 衡量方法

同一任务只需要一次明确点击；没有图标才能读懂的入口；320px与文字放大不横向溢出；键盘焦点可见；下载链接仍对准当前文件。没有用户研究或转化实验，不能承诺“所有访客一眼喜欢”或宣传效果提升百分比。
