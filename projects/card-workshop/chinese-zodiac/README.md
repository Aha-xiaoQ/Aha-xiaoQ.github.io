# 生肖剧场 · 小栖的十二种角色

解压离线包打开 `index.html`，源码目录的入口是 `dist/index.html`。纯HTML/CSS/JavaScript，无构建步骤，无外部字体、远程接口、追踪或设备传感器请求。

## 玩法
点击十二生肖座位或收藏卡选角；鼠标移动或触屏轻拖卡面可观察背景、人物和道具的独立位移、倾斜与流光。左右按钮循环切换；按钮焦点内可用左右方向键。
“舞台动起来”控制自动巡游与道具浮动；“安静欣赏”关闭全部动态，并遵从系统减少动效偏好。触屏保留纵向滚动。

## 角色清单
鼠·杰瑞；牛·牛魔王；虎·悍娇虎；兔·朱迪；龙·敖丙；蛇·白素贞；马·白龙马；羊·喜羊羊；猴·孙悟空；鸡·四眼天鸡；狗·阿奇；猪·猪八戒。
每张都是小栖保持银发、金瞳、猫耳身份的同人COS，而非扮作原角色本人。

## 设计与资源
12张独立透明人物，12组独立剪纸场景和前景道具。卡片由场景、纸盘、人物、前景、遮光、箔纹、高光和票根框组成，按不同系数移动，不是将一张平面合成图旋转。
页面采用高质量透明WebP，收藏册使用512×768懒加载缩略图，原始PNG仅留源码art-originals。只给主卡启用持续场景动效，离屏/后台停止动画和逐帧工作。
本项目独立于月份和星座系列，不覆盖已有作品。
