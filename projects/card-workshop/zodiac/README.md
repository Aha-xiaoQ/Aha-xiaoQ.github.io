# 黄道秘藏 · 小栖十二星座闪卡

解压离线包打开 `index.html`；源码入口为 `dist/index.html`。纯静态HTML/CSS/JS，离线可用，无外部字体、远程API、埋点或传感器请求。

## 操作
点击十二宫星盘或收藏图鉴选择星座；移动鼠标或轻拖卡面观察立体层级和流光。左右按钮循环切换；按钮获得焦点时可使用左右方向键。

“星光巡游”控制自动倾斜、星轨和能量边框；关闭后仍可手动倾斜。“静态欣赏”立即关闭全部运动，且自动遵从系统减少动效偏好。触屏保留纵向滚动，不请求陀螺仪。

## 作品结构
十二张独立角色插画，搭配火、土、风、水四套卡框与材质；每张有独立象征场景和艺术星图。星图属于奇幻视觉设计，不是精确天文观测图。

卡面分别包含场景、旋转星盘、星图、透明角色、前景粒子、遮光、元素卡框、光谱镀层与玻璃高光。主卡另有大尺度星图、星尘和切换凝聚效果，运动不是整张平面图旋转。

部署目录使用高质量透明WebP；原始PNG保留于源码 `art-originals/`，不会随离线包或页面加载。缩略图独立512×768、懒加载。离屏与后台停止帧更新；静止层不重复写CSS。

本系列独立于“十二月光”月份卡，不覆盖月份作品。
