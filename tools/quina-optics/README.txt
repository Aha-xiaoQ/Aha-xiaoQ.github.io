启娜的光之工坊 · 第01期交互实验

解压后用 Edge 或 Chrome 打开 index.html。

点击“为什么能准直？”或“为什么会分色？”可打开原理图。
“原型依据”内可打开本地厂商手册（Oxxius镜像归档，PDF第11、37、39页）。

光学实验：转动光栅、调整狭缝、切换光源、加入样本，观察光路与光谱的变化。
点击右上角“拆开转轴”，打开机械装配查看器。

拆开转轴：打开外壳并展开结构；用“展开程度”滑杆装合或拆开。
轴承特写：单独展开内外圈、滚珠、保持架和密封。
拖动旋转，滚轮缩放；在结构列表中选择零件，可单独检查。
“运行传动”会先合拢零件，再演示蜗杆和蜗轮联动。
“完整装配”或“复位”恢复整体；右上角“光学实验”返回光路。

装置依据 Czerny–Turner 光谱仪原理；转轴传动参考 Thorlabs CR1-Z7 的公开原理。
两个视图分别呈现光学原理与自主设计的机械结构示意，不是厂商 CAD 的精确复刻。
光源和样本为模拟数据，屏幕颜色为波长近似示意。
