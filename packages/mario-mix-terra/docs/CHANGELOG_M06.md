# 0.4.2 · 体验与发布检查

## 新增
- 可选的操作速查，使用实际绑定生成提示；首次提示条可关闭，顶部入口常驻。
- 本地反馈模板，剪贴板失败时可以手动选取；不自动上传。
- 新增 quick-guide 与 adventure-help 两个模块，依赖通过端口提供。

## 修正
- 持久显示偏好读取成功后正确显示保存状态。
- pagehide 的 persisted 页面不再销毁界面监听器；普通离开仍执行清理。
- 手册期间清空键盘保持状态，原手柄轮询不转发到世界；设置弹窗补齐可访问名称。
- 旅途状态作为可展开的次要信息，原节点与状态绑定保留。
- 候选页素材说明链接指向第三期，而不是第一期。
- 构建清理已登记且未手改的过期产物；手改旧产物会阻止构建，未登记文件保留。

## 不变
地图、物理、战斗、掉落、原媒体、默认键位、稳定试玩和前两期文件不改；不引入城堡、不更换引擎。29 个模块与 33 个兼容片段并存，完整旧角色仍不能任意套入新地图。
