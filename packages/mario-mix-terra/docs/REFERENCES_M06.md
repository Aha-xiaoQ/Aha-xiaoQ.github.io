# 体验检查依据

查阅日期：2026-09-17。只借鉴原则，没有复制第三方主题、代码、图片、音频或文字。

| 来源 | 采用的原则 | 实际范围 |
|---|---|---|
| W3C APG Dialog (Modal) | 命名、初始焦点、Tab留在窗口、关闭与返回 | 使用原生dialog并补键盘输入隔离；不等于完整无障碍认证 |
| Game Accessibility Guidelines · interactive tutorials | 在需要时说明操作，降低记忆负担 | 只交付可选操作速查；交互训练不在此版本 |
| Godot · Scene organization | 单一职责、依赖注入、生命周期所有权 | 手册与输入/存储/游戏状态通过端口连接，不迁移引擎 |
| GOV.UK · Writing for user interfaces | 清楚标题、具体动作、面向访问者的异常提示 | 反馈复制失败有可操作降级，不展示制作过程解释 |
