# ADR-002 · 先打通可验证的关卡接入，再逐关/逐角色迁移

日期2026-09-17。M02有15个已迁出模块，却没有任意地图/角色接入口。用户提出其他开发者制作1-4应能快速接入，这是与“继续拆文件”不同的验收目标。

决定：保持原第三期可回归，用单一宿主桥接一个数据驱动原型，建立base-map + character + overlay + stage rules四层。形成起步脚手架、能力拒绝、房间生命周期、原型HUD和逻辑音频；不为新内容增加wrapper。以匿名内容ID测试不需要改核心。

取舍：保留旧物理意味着legacy-terra-v1暂时封闭；platform-v1是几何原型，有自己的明示参数，不能称真实泰拉动作已迁移。为了不把未完成城堡掺入，使用原创两房间样例，不交付冒名的原版1-4。底图原样、机关时序与角色可通关必须分别验收。

下一项真正门槛：一个完整真实actor可从旧房间依赖迁出并接入两张数据地图；在此之前不宣称“旧角色即插即用”。然后实现1-4共用机关/结算，不再以迁出模块数量代替开发者接入验证。
