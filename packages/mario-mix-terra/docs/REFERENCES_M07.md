# 界面研究与取舍

研究日期：2026-09-19。借鉴信息结构和交互，不复制游戏美术、界面素材或字体。

- Celeste 官方变更记录：https://www.celestegame.com/changelog.html 。按键提示用明确动作而非孤立图标；改键和菜单退出后的刷新要一致。本版将角色、动作和实际绑定一起展示，重置/重试有独立流程。
- Xbox Accessibility Guideline 101：https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/101 。文字检查涵盖HUD及所有菜单，强调尺寸、对比、字体与重排。本版分离低分辨率画面与文字，窄屏使用正常CSS字号；不是XAG合规认证。
- Xbox Accessibility Guideline 112：https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/112 。菜单焦点、返回行为和重排顺序保持可预测。本版集中入口、确认取消优先，并为方向键和手柄菜单使用相同可见焦点。

不照搬网站的斜切大卡片进入游戏。当前森林/暖金方向保留，减少侧栏说明、边框层数及重复入口；画面与角色仍使用原素材。高DPI额外画布的性能、自然游玩理解度和读屏效果需真实测量，不由静态研究推断已达顶级。
