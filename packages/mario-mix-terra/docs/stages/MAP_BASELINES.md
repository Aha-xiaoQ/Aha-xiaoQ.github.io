# 地图基准清单

现有 `content/maps/base-1-3/reference.json` 完整保存 M02 `createLevel13().compile()` 的解码数据；哈希和来源见同目录manifest.json。每次构建比对解码输出，禁止通过重写基准来掩盖偏差。

`content/extensions/maps/base-1-3/map.json` 是该底稿平台数据到接入格式的几何参考，只供封闭第三期清单引用，不是旧第三期全部怪物、触发、地形与美术的通用移植。

`lab-main`、`lab-bonus` 是本轮原创验证地图；不是1-4，也不是“原图复刻”。生成world-1-4时只复制其结构形成draft。

后续原图每关需要：来源和版本、数据与图片许可、尺寸/坐标/层/碰撞、出生点与房间连接、隐藏条件与机关时序、敌人与终点规则、验证截图/回放、地图版本hash。角色扩展单独引用基准并加overlay，不能覆盖。地图截图公开可见与代码/图像/音乐再分发许可是两回事。
