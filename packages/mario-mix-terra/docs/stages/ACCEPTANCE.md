# 新关卡提交门槛

1. 在全新源码副本使用文档创建新ID，不修改主循环；提供新增/修改文件清单。
2. 底图来源、版本、地图/素材许可记录独立；对照几何与机关时序，不能只验证一张截图。
3. 每个允许角色实测入口、边界、坑、移动/单向平台、检查点、死亡、失败、重试。
4. 奖励房进入/退出、一次领取、防重复、返回位置、关闭/重进会话、无过期监听或声音残留。
5. 旧第三期回归；键盘/手柄/触屏、菜单和改键、失焦、热插拔；回车/空格不能同时启动原菜单。
6. 正式1-4还需其机制齐备和真实角色动作；原型几何占位不能满足正式发布验收。
7. 记录候选SHA、设备、步骤、证据、未验证项；数据合法≠通过自然关卡≠获授权≠已上线。
