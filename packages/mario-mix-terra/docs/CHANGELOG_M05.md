# M05 / 0.4.1 · UI 精修

基于M04/0.4.0，日期2026-09-17。发布候选，不等于线上已更新。

## 可见改动
统一菜单、角色选择、按键设置、侧栏和触屏按钮视觉；原角色选择从窄六列改为三列两行，保留顺序与原处理函数。快捷栏/生命魔力加底板，活动项突出；拾取提示整理为名称+效果，内容和队列不改。新增专注模式、大号菜单文字、高对比及减少界面动效。

## 有意交互差异
点击专注或聚焦显示控件时清空保持的按键，避免继续移动；显示控件中的Space/Enter/Escape不再漏给游戏。快捷提示随实际键盘绑定更新。显示偏好存储在新键，不清理或迁移旧存档；不跨刷新恢复专注状态。

## 没有修改
地图、碰撞和固定时钟、生命/伤害/武器数值、掉落与库存事务、音频时序、默认键位、关卡实验能力均未扩大。前三期线上文件、未完成城堡、主站外观、小手柄图标及路由不在修改范围。

## 工程
增加3个实际调用的UI模块、2个桥接，总计27模块/6桥接/33兼容片段。CSS候选附加而不污染原版重建。浏览器测试等待条件改为函数形式，适配现有CSP，未放宽unsafe-eval。

## 已知限制
偏好尚无实体手柄菜单导航验收；竖屏HUD缩放不在本轮。真实HTTP/ESM、持久存储刷新、Windows、音频听感和自然通关仍需实机；大号文字不覆盖固定像素HUD，减少界面动效不禁用世界震动。
