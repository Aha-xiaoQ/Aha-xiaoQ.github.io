# M02 行为差异清单

## 保持一致

默认动作、已有按键键位、坐骑重排算法、旧 layout 迁移、手柄死区范围、键盘逻辑映射与释放语义、世界物理、地图、伤害、奖励、音频与现有游戏内容均保留。原底稿完整重建的校验值不得改变。

## 有意修复（不是纯重构）

1. **默认配置回导**：底稿默认 interact 与 recall 共用手柄索引6，但导入函数把它当作冲突。M02 仅允许这对既有上下文共享在6上回导，不修改默认键位、不开放任意重复键。旧 toolNext/recall 共享规则保留。
2. **重复打开与外部关闭设置**：同一会话只拥有一个轮询定时器；关闭、原生 close 和 pagehide 清理资源。原来已暂停的游戏不会因为关闭设置被恢复。pagehide 不在后台恢复游戏。
3. **迟到导入**：取消选择文件不再抛错；读取大文件期间关闭并重新打开设置，旧会话结果不会应用到新会话。
4. **表格可访问名称**：绑定按钮加上动作与设备名称，显示文案与默认布局保留。

没有改游戏难度、手感、地图、武器、Boss、字体资源或 HUD 风格。此差异说明必须与回放/单测一起审阅。
