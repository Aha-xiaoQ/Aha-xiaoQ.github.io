# 操作速查

顶部“操作速查”随时打开冒险手册。首次游玩的提示条可关闭，不强制进入教程。提示读取当前改键配置；键盘与手柄提示可切换。

游戏进行中打开手册会暂停；关闭后仅恢复手册自身触发的暂停。原本已暂停、页面离开或进入后台时，不会自动继续。

手册包含移动、跳跃、工具、地下入口、坐骑和暂停。它是按需查阅的说明，不是跟踪训练完成度的交互教程。其他角色的专属操作仍见右侧角色说明。

“遇到问题”提供本地反馈模板，只包含版本、角色、场景、输入方式、画面尺寸和复现步骤占位。不会自动发请求、不读取存档。剪贴板不可用时，文本会选中以便手动复制。

“不再提示”仅设置独立的 marioMix.help.v1 偏好，不清空游戏存档和按键配置。浏览器禁用存储时仍可关闭本次提示。显示偏好中的大号文字不放大固定像素 HUD；减少界面动效不关闭世界震屏或闪光。
