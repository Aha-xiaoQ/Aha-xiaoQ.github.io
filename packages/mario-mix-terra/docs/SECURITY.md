# 本地工具安全边界

路径授权复用经过悬空链接修正的 lstat 逐段检查，拒绝链接、junction、父级非目录、Windows 保留名、冒号流、路径穿越和敏感目录。读取尽可能 O_NOFOLLOW；输出采用独占临时文件和 rename。

这不是抵御恶意本地进程持续替换目录的沙箱。操作期间工作区必须可信、无并发写入；SHA 和 CRC 用于完整性/冲突检查，不是签名。源媒体、模板和项目文件也属于需要审阅的输入。

服务器仅监听 127.0.0.1，只读 dist，限制 Host、Origin、方法、路径和 MIME。不公开 .local、用户资料或源根目录。不提供写接口，不需要令牌。外部 PR 测试不应配置生产密钥或自动部署权限。

更新器只新增工程、下载包与资料接入，根文档/命令采用明确追加。回退拒绝覆盖应用后的新改动。

源代码示例和原游戏仍含可选网络媒体及已有缓存路径，保留而非安全审计认证。
