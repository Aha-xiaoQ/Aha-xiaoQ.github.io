# Mario Mix · Terraria / M02

在熟悉的横版关卡中体验泰拉瑞亚的武器、建造与探索。这份工程供开发者进行小范围、可验证的改动；默认移动、战斗和关卡保持第三期底稿行为。

[从这里开始](START_HERE.md) · [如何贡献](CONTRIBUTING.md) · [源码地图](docs/MODULE_MAP.md) · [任务](docs/TASKS.json) · [验证结果](docs/TEST_REPORT_M02.md)

**M02 的重点**：让按键设置不再直接管理所有游戏输入与定时器；以独立配置模型、捕获、路由、UI 会话和清理范围衔接现有游戏。附机器可检查的模块契约与贡献任务，不是一次性把旧引擎重写。

菜单外观与玩法大体不变。明确修复：默认按键配置因已有的上下文手柄共用键而无法回导；重复打开/原生关闭设置时的会话清理；关闭后迟到的文件导入不应用到另一轮窗口。

候选不是已发布版本。第三方图像、音乐、角色和参考代码各自的权利仍适用；请读 upstream/NOTICE.txt、docs/RESOURCES.md。
