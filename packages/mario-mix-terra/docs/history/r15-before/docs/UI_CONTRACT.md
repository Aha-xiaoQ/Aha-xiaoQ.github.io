# M05 游戏界面契约

## 一套视觉，三层职责
- **世界与HUD**：像素渲染、快捷栏、生命/魔力、Boss血条、拾取说明。保持M04坐标、触摸命中区域及队列寿命；UI不能推进物理、发放道具或消耗资源。
- **菜单与设置**：HTML/CSS承载角色选择、暂停、改键、音量和显示偏好。使用低纹理深绿底、暖金主动作、冷色魔力和暖色生命标记；文字保持水平，不移植个人站的斜面大字卡片。
- **说明与调试**：完整说明默认折叠。原权利声明/素材状态仍可进入；几何实验场保持?dev=1显式入口。

## 源码边界
`src/ui/adventure.css`是候选专用样式，选择器以`body[data-terra-ui="m05"]`限定。原console.css和HTML模板保留用于底稿重建。
`adventure-render.mjs`仅绘制传入的快照，依赖的图标回调不得修改玩法。`hud-paint.bridge.js`读取兼容区现有状态并调用它，保留旧t15Hud测试快照。
`display-preferences.mjs`只存储已知枚举；存储键`marioMix.presentation.v1`独立于存档/改键。无权限或损坏数据时回落默认并显示未保存，不保证所有浏览器下存储可用。
`adventure-shell.mjs`负责DOM挂载、偏好、专注切换及快捷提示。借用既有lifetime清理事件，候选专用挂载在第三期闭包内；不引入新的主循环/动画驱动。

## 输入和生命周期
新显示控件仅在焦点位于`[data-terra-display]`时拦截游戏输入。Tab可正常导航，Enter/Space触发按钮，Escape关闭显示区域返回Canvas。利用原最早的输入所有者分流，不能再注册一个晚到的监听器假设能撤回攻击。
切换专注/进入显示控件时清除被保持的输入，这是为了避免焦点转移后角色持续移动；不会触发暂停或重新开始。原改键对话框仍由既有设置会话拥有暂停恢复，关闭后更新快捷提示。
快捷提示读取实际绑定，不把空格/J永久写死。完整改键表保留所有动作、键盘与手柄字段。

## 尺寸与可读性
正常菜单正文16 CSS px，紧凑说明14px；大号模式20/18px。角标等非关键装饰可更小。主按钮至少44px高。HUD保留原固定坐标并数字+图形同时标识生命/魔力，既有可点击工具槽不移动。
大号模式**不是全屏UI等比例缩放**；竖屏像素HUD仍偏小。高对比提高面板/文字与HUD底板可辨识度，未做WCAG/XAG认证。
减少界面动效优先用户偏好并尊重系统减少动态效果，影响界面过渡与拾取提示淡入淡出；不宣称禁用游戏场景闪光/震动。
