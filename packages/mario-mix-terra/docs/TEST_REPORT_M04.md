## 本轮发现与修复

无效legacy关卡先前可能通过校验却被旧驱动忽略，现固定为第三期封闭组合；未知音频key在构建前失败；退场时禁止旧代次/析构事件串入新场景，防止事件载荷覆盖生命周期标识；快照返回副本。无效武器ID现在拒绝，正常已登记武器与箱子按旧片段验证。

最初测试比较不同VM的对象原型造成假失败，已明确序列化后比较；没有删除用例。新增模块数断言从22更新为24、桥接2更新为4；新增三项真实任务后，原任务数量断言15更新为18，任务权限和证据检查保留；旧118个测试保留。玩家入口DOM检查改用两个独立页面，避免同一文档反复注入CSP和运行脚本，未移除CSP或改变浏览器策略。
