# 资源管理与许可

content/resources.json 登记 ID、相对路径、媒体类型、字节数与 SHA-256。assets/embedded 保存从上传脚本中解出的数据 URI，assets/audio 保存基础音频。content/audio-manifest.json 保留底稿播放元数据。

M01 为降低迁移风险，在构建时把这些二进制重新编码给旧加载器使用；网页把它们放在 resources.js，单 HTML 则内嵌。尚未引入按场景流式加载、自动压缩或 srcset，不声称下载体积减少。源文件管理与运行时资源策略是两个阶段。

旧可选远程图片/音乐、缓存和失败降级保留。当前原媒体缺失时某些新增敌人不会生成，原始离线游玩范围不等于联网完整内容。网络来源扫描记录在 REMOTE_SOURCES.json，其中有构建期无法展开的 URL 前缀；不是穷尽运行时网络请求的授权清单。

所有资源继承 upstream/NOTICE.txt 与源码中的来源说明。当前没有把整个游戏或美术重新授予 MIT。构建哈希只验证完整性，不证明授权。贡献新素材必须附来源、作者、许可证据和适用范围。

源码归档禁止字体文件；页面采用原来的系统字体栈。不修改或分享用户字体。
