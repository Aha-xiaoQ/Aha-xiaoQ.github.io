## 对照覆盖

新增设置测试中的80组旧配置、32组坐骑键分配、1,200次键盘事件与100轮窗口生命周期是数据覆盖，不额外算成1,412项测试。浏览器的30次重复窗口开关同理。13段游戏回放包括开始、移动、跳跃、攻击、暂停/保持/恢复、隐藏场景准备、建造结果、Boss召唤、战斗、奖励及返回；**不代表自然完整通关**。

检测到原版默认配置导出再导入失败：interact与recall原本共享pad6，旧校验器却拒绝这个默认组合。M02保留默认动作和键位，只允许这个既有上下文组合；其他冲突仍拒绝。此项明确是行为修复，见 BEHAVIOR_CHANGES_M02.md，不把它算作所有行为与原版完全相同。

## 运行环境和不能扩大解释的结论

Linux / Node.js 22.16.0 / Python Playwright / 系统Chromium。本轮真实探测本地HTTP页面返回 `ERR_BLOCKED_BY_ADMINISTRATOR`，没有修改或绕过浏览器策略。

浏览器通过set_content运行完整游戏HTML、保留原CSP、固定测试种子并阻止外部请求。内嵌游戏素材真实；可选网络资源未下载。地址导航与真实ESM网络加载、跨刷新localStorage、原生导出文件落盘、音频听感和实体手柄不是这些夹具能证明的事项。没有性能提升、完全离线或无障碍认证的声明。

设置窗口使用真实DOM事件；pad采样和文件延迟是可控输入，不能称为实体设备验收。当前有10个由窗口视图作用域管理的监听器；开关设置时轮询作用域最多一个，关闭为零。其余旧游戏监听器仍在兼容区，未迁完。

15个模块实际接入候选。33个compat片段仍有共享状态，46号片段现在是适配插槽，**不据此称整个游戏已解耦**。38是选定wrapper正则的当前命中预算，不是全动态调用图。

## 交付复跑

最终源码ZIP解压后执行 `npm run verify`、`npm run pack`；再次打包校验值应与交付源码一致。源码包SHA写在旁置JSON中，不能把自身SHA写进自己造成循环。网站更新ZIP另有安装/回退测试与FinalVerification记录，其结果不是本源码的Windows/线上验收结论。
