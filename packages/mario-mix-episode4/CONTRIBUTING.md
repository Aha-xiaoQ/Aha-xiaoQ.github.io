# 第四期源码贡献约定

先在仓库 Issue 说明修改范围。每次只修改一个明确问题，不混入地图改版、音轨更换和全仓格式化。

1. 运行 `npm run verify` 建立未修改基线。
2. 参照 `docs/MODULE_MAP.md` 修改相应片段或样式；运行 `npm run check` 和 `npm run build`。
3. 记录与 R43 基线的预期差异，新增对应测试。新游戏版本使用独立版本记录，不篡改旧基线伪造完全一致。
4. 在浏览器对照索尼克及奥日的选择角色、移动、跳跃、受击、存档、重试和结局。音频额外核验暂停/恢复、静音、死亡、切换角色及上升段循环。
5. PR 附实际环境、操作步骤、结果和未测试项。截图或模拟手柄结果不能代替真实设备结论。

新增素材需要来源及许可证据。保留原声明，不将未知授权素材重新标注成 MIT。仓库写入、合并及在线试玩替换应由维护者按本次授权分别处理。
