# 用地图工坊制作下一关

当前为本地验收候选。模型、导出、平台驱动测试已执行；真实浏览器界面操作尚待验收。

## 打开

网站本地预览：在地图册点击“打开地图工坊”。

开发包：安装 Node.js 22 或更高版本后，双击 Open-Map-Editor.cmd。不需要安装 npm 依赖。也可运行 node scripts/editor-launch.mjs。服务仅监听本机；关闭启动窗口会停止服务。

## 做出第一张地图

1. 选择“新建空白”，或者“从底图创建”选择一个关卡。现有底图会完整复制到个人工程，原文件保持不变。
2. 左侧选择“地形与碰撞”和地面，用画笔拖动。大面积地面使用矩形；挖坑用橡皮；相连区域换材质用填充。
3. 选择单向平台可画能从下方跳过的平台。砖纹块、金色块是外观材质，不自动赋予可破坏或出奖励的行为。
4. 选择“游戏对象”放置出生点、金币、出口、危险区或基础敌人。把出生点放在地面上方，不要埋入地面。
5. 用框选工具选中元素，再拖动选中的元素，或用右侧坐标、方向键调整。支持复制、粘贴、删除。
6. 点击“地形试跑”，检查跳跃距离、缺口和平台位置。试跑使用现有平台驱动的几何角色，不是下一关正式角色手感。
7. 点击“导出工程”，保存 .qmap.json；下一次“打开工程”继续。自动保存只保留当前浏览器、当前站点的一份本机草稿。新建/打开前，请导出要保留的其他工程。

## 三种视图

- 结构图：查看实心地形、单向/运动平台和对象位置。
- 效果预览：以示意纹理表达地块外观，不是原版截图或最终美术。
- 秘密与路线：显示源数据保留的隐藏标记，右侧可读奖励内容和连接记录。普通效果视图隐藏秘密标记。

参考机关没有自动变成可玩机制。具有参考关联的地块只能整体移动/删除，不能用画笔切碎。关联记录随整块移动/删除，未经修改的原始参考仍保存在工程 reference 中。复杂机关配置编辑、完整跨房间路线编辑仍未开放。

## 操作与保存

|操作|方式|
|---|---|
|连续绘制|画笔拖动，一次笔画对应一步撤销|
|撤销 / 重做|工具栏，或 Ctrl/Cmd+Z / Shift+Z|
|平移|空格加拖动，或者选择平移工具|
|横向滚动|Shift 加滚轮|
|复制 / 粘贴|框选后 Ctrl/Cmd+C / V；粘贴落在当前视图左上方|
|取消笔画|Esc；取消的笔画不会保存|
|调整尺寸|右侧按格输入；缩小遇到越界元素会拒绝，不自动裁剪|
|工程备份|导出工程；本机存储失败时务必导出文件|

## 交给开发者

“导出开发包”会先执行现有运行时的格式检查，再导出 ZIP：

- maps/、stages/、audio/ 对应开发源码的 content/extensions/。
- 使用源码已有的 lab-runner 实验角色，不覆盖角色配置。
- 每个工程/区域使用独立标识；重复导出同一工程代表修订。合并前保留旧副本。
- 运行开发源码的关卡检查与构建，在关卡试验场显示草稿并选择导出的关卡。
- 仅导出当前区域；跨区域管道、水下驱动等未支持项会阻止试跑/开发包导出。工程文件仍可完整保存。

不要把开发包当作完整工程备份：装饰、参考信息、未实现奖励属于编辑工程，目前不进入基础运行时。.qmap.json 才是后续继续编辑的文件。Tiled 仍是现有对象层导出，尚未提供无损回写。

下一关制作建议先用本工具完成地形白盒、出生点、基础危险与出口，通过实际跳跃验收，再接正式角色、奖励系统和美术。


## 对象、管道与本地试玩（2026-09-19）

- 普通起点和终点重复放置会移动原对象。管道落地点可以有多个；旧工程可用“清理旧版重复起点”，保留已有管道和检查点引用，操作可撤销。
- 游戏对象层选择金币或敌人，用矩形工具框出区域，按“批量间距”铺设；单次最多 2000 个。拖画笔仍可逐个放置。
- 先放置“管道落地点”，再框选“管道入口”，在右侧选择目标区域和带坐标的落地点，点击连接。双向通行要分别设置两端入口；不会自动把多个管道连接到同一处。
- “新增区域”创建新的空白房间。试玩从当前区域开始，包含管道能到达的区域。悬空连接与被地形挡住的落地点会阻止启动并提示。
- “试玩地图”使用简单人物和现有平台驱动；方向键移动，空格跳跃，J 攻击，↓ / E 进管道。支持金币、行走敌人、危险区、终点及管道切换。参考层的问号奖励、游泳与复杂机关没有自动实现。
- “下载离线试玩”导出一个 HTML 文件，双击后点击开始即可体验，无需安装或联网。它保留试玩需要的地图、素材和运行代码；要继续编辑请另存工程文件。
- 效果预览、地图册与试玩共用现有 1-1 的像素材。起点显示马里奥，栗宝宝和乌龟使用各自贴图；其他缺少贴图的敌人仍为具名参考标记。选中地块后可导入 PNG 地块图片（16–256 像素正方形，边长为 16 倍数，500 KB 内）；素材保存在当前区域，随工程和离线试玩导出。


### 地形与敌人素材
树顶、蘑菇平台、平台、管道、珊瑚和炮台各有独立素材；地下、水下与城堡按区域切换配色。敌人可按种类选择，拖动、删除或使用矩形批量放置。旧工程会补齐缺失的底图材质信息，保留已有编辑。试玩使用基础敌人行为；贴图齐全不代表复杂机关与全部原版 AI 已实现。

## 试玩与视图（1-1 基准）

方向键或 A/D 移动，按住空格跳高，Shift / J / X 加速，火焰形态按这些键发射火球，↓/E 进入管道。先用“从底图创建 → 1-1”体验已有网页游戏布局；旧草稿会保留自己的编辑。奖励砖逐格消耗，变大后可顶碎空砖。

效果预览呈现地形与对象；秘密与路线显示隐藏奖励、管道连接去向。画布可按住中键或空格+左键拖动，也可使用 Shift+滚轮或左右移动按钮。云素材放在装饰层时不参与碰撞。

1-1 已有连续输入通关回归；其他关卡与复杂机关仍需逐项验收。

树顶、蘑菇平台：横向拖动放置完整平台；管道：纵向拖动调高，宽度固定两格。放置后右侧「组件尺寸」可修改宽高，平台整体高度 0 表示自动接地。橡皮删除整组件。管道需要穿行时，另在游戏对象层放管道入口并连接落地点。
