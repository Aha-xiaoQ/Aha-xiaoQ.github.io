# 用地图工坊制作下一关

更新于 2026-09-20。地图工坊为测试版，实现已合入主分支；支持马里奥试玩与离线导出。复杂机关、完整路线和设备兼容性仍需继续核验。

## 打开与创建

从网站“工具”页打开“马里奥地图工坊”，或从地图册进入。开发源码可运行 `node scripts/editor-launch.mjs`（Node.js 22+，无需安装依赖）。

1. 点击“从底图创建”，选择世界与关卡；32 关参考底图会复制到个人工程，不修改原始地图。也可新建空白地图。
2. 用画笔、矩形、填充和橡皮编辑地形。管道、树平台与蘑菇平台按完整组件放置，右侧可调整尺寸。
3. 放置出生点、敌人、金币、奖励砖和出口。参考奖励与机关已接入试玩，但复杂组合仍需自己试走。
4. 框选元素可移动、复制和删除；跨区域管道需要选择目标落地点并连接。
5. 点击“试玩地图”，检查跳跃、奖励、敌人和出口。默认使用马里奥；更换人物贴图仅改变外观，不改变能力。
6. 导出 `.qmap.json` 工程备份，下次打开继续编辑。本机自动保存仅属于当前浏览器与站点，清理浏览器数据可能丢失。

## 试玩与离线版

- 键盘方向键 / A、D 移动，空格跳跃；Shift / J / X 加速或发射火球；下方向下蹲、进入竖管，上方向攀藤蔓。横向管口向入口方向移动。
- 支持触屏虚拟手柄及外接手柄；按设备选择布局，以画面提示为准。全屏默认隐藏详细信息与虚拟手柄，可重新显示。
- 网页开发者试玩默认自动在死亡位置附近的安全陆地或平台复活，便于调试；不是原版生命规则。
- “下载离线试玩”导出当前地图的独立 HTML；“下载完整连续版”包含顺序闯关与自由选关。文件生成后点击保存，下载后直接打开游玩。
- 离线初始生命默认 3 条，可选 1–30 条；可勾选开发者试玩。音乐、音效、字体与制作信息随文件嵌入。
- 离线 HTML 是游玩文件；继续制作必须另存工程。旧下载不会自动更新，请重新导出。

## 视图与编辑操作

效果预览显示地块和角色素材；结构图用于检查碰撞；秘密与路线显示隐藏奖励、参考标记和连接。画布可用中键或空格加拖动平移，Shift 加滚轮横移。

|操作|方式|
|---|---|
|绘制 / 橡皮 / 矩形 / 填充|B / E / R / F|
|框选 / 吸管|V / I|
|撤销 / 重做|Ctrl/Cmd+Z / Shift+Z|
|复制 / 粘贴|Ctrl/Cmd+C / V|
|取消笔画|Esc|
|工程备份|导出工程|

平台和管道组件按其整体结构调整；缩小地图遇到越界对象会拒绝，不会静默删除。

## 开发包与范围

“导出开发包”用于接入通用开发运行器；它与马里奥试玩 HTML 不同，导出前会检查运行器支持范围。工程文件保留所有房间、素材与参考信息，不要用开发包代替工程备份。Tiled 仍为对象层导出，不支持无损回写。

试玩已接入游泳、藤蔓、弹簧、升降/平衡平台、隐藏管道和终点结算等机制。32 关底图不等于全部路线已通过自然通关验收，循环城堡仍有有限地图回退实现。魂斗罗 1-2 角色迁移尚有问题，暂不开放；前三期独立游戏和奥日开发状态不受影响。
