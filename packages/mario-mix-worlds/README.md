# 混合马里奥 · 关卡地图册 W02

世界 1–8 的 32 关参考底图、63 个区域与 33 个循环路线分段。用于选择角色方案、核验地图和开发机制，不是 32 关完整复刻游戏。

完整开发包：`npm run verify`，随后 `npm run atlas`。地图册位于 http://127.0.0.1:4196/atlas/index.html。

实验运行：`npm run dev`。打开 http://127.0.0.1:4195/play.html?dev=1，进入关卡试验场并显示开发草稿。
