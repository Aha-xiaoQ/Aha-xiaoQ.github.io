## 维护者复验顺序

1. 应用后先执行 `npm run game:check`、`npm run game:test`。
2. 执行 `npm run game:audit`。missing/different 会非零退出；保留较新文件，核对来源，不通过倒退游戏来绕过保护。
3. 执行 `npm run game:build`，记录真实候选 SHA，再开 `game:dev`（4180）与 `game:reference`（4181）对照游玩。
4. 已具备 Python Playwright 与浏览器时，从 `packages/mario-mix` 运行 `python scripts/browser-compare.py`。不要把未安装依赖或未运行记为通过。
5. 完成 ACCEPTANCE 中人工场景，把证据与候选 SHA 放入 RELEASE_REVIEW。`game:release-check` 不会自动发布。
6. 执行 `npm run journal:build`，复核新增工程资料及原 `npm run check` / `npm test`，最后由维护者审阅、提交和推送；核对远端 Actions 首次实际结果。

本包首次外部 PR 的任务记录在 `docs/WORK_ITEMS.json` 中保持待处理，不会自动把它写成已经协作成功。
