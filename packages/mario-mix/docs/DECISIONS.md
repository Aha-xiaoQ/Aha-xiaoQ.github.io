# R05 工程决定

**ENG-ADR-001｜保持用户在验收的 R04 视觉不变。** 不修改主站 HTML 模板、样式或路由；只追加项目工程资料的数据入口。运行 journal:build 会按原有模板生成资料页，不设计另一套页面。

**ENG-ADR-002｜留在当前仓库建立独立包。** 使用 packages/mario-mix 与 npm --prefix，无依赖安装；先跑通小 PR，而非立即迁仓。

**ENG-ADR-003｜先做第一期的小切片。** 第一处控制片段完整读取且可核对。二/三期巨大 HTML 尚未完整获取，所以不向它们盲目套代码。既有 BASE/ENG 大任务不因这个切片完成就一律标 done。

**ENG-ADR-004｜纯逻辑 + 薄桥接 + 有锁的候选构建。** 旧闭包主体保持，生成物仅供独立本地端口预览。不把生成物继续当源码，也不向网站注入未经审核的 PR 页面。

**ENG-ADR-005｜三层证据分开。** 对照片段自动测试、真实游戏虚拟步进、真实设备/声音/通关分别记录。没有执行的检查始终 pending。

**ENG-ADR-006｜工程可协作不等于许可和发布就绪。** 当前只能说新增贡献通道；远端 CI、保护规则、第一次外部 PR、正式许可仍有维护者确认事项。
