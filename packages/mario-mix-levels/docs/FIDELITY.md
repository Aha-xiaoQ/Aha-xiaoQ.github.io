# 地图来源、转换与待复核项

## 不是官方数据包

来源为 FullScreenMario / umaim/Mario 的固定提交 `980c275358704a49f868567aeec5bdfb347c4781`，按 `Source/settings/maps.js` 转录第一世界玩法相关声明，宏语义参考该提交的 `Source/FullScreenMario.ts`。来源和许可全文见 NOTICE.md、licenses/。

本轮的“已转录”表示地图数据和对象位置已录入、可生成并测试。**不表示已经对任天堂原作做逐格、逐帧或全部路线的认证。** 来源复刻项目本身可能与原作有差异，必须另行核验。没有使用ROM或提取原作音频。

源单位每格8，转换后每格16像素；`x'=2x`，普通对象顶边`y'=208-2y`。Floor延伸到240像素底部；Pipe宏把高度加到源y再转换；树冠按单向平台处理；隐藏砖仅作为标记。原始操作序号保留在`coverage`和`ref-…`ID，便于追溯。

## 明确尚未完成

敌人行为、顶砖和奖励生成、隐藏砖显形、食人花、循环升降台的循环再生、原作移动平台时序、火焰棒旋转伤害、Boss战、断桥与结算演出尚未实现或认证。未实现对象显示虚线，不作为其他敌人或假机关运行。1-4几何模板不是奥日关卡成品。

背景装饰、源项目开头的标题文字及纯滚动限制器没有转入当前碰撞数据。跳关只保留目标声明，未提供的世界不连接到假地图。

## 复验记录要求

每次地图修订记录：关卡/房间、原作参考版本、参考截图或时间段、对象ID、原坐标、修改后坐标、原因、审核人。先核对地形与出生点，再核对机关/敌人时序和通关。自动结构检查不能替代可达性、手柄或自然通关；不要为了测试角色能过关擅自填平原地形。

Tiled导出包含collision、gameplay、reference-markers三个对象层，不含贴图tileset；当前只能编辑检查，修改TMJ后不会自动影响工具包或M06。
