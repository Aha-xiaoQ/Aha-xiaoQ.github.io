# 结构与职责

|位置|责任|
|---|---|
|data/reference/world-1.json|源坐标、物体参数与房间连接，包含固定参考提交|
|src/reference.mjs|确定性的坐标转换、宏展开、未实现行为清单；遇到未知宏直接失败|
|data/generated/|只读扩展 JSON 与覆盖报告；由构建生成|
|data/campaign.json|32个主线位置的制作进度、角色方向、模板状态与后续动作|
|src/map-view.mjs|地图结构绘制与 SVG 预览，不推进模拟|
|ui/workbench.mjs|场景选择、键盘/触控、暂停和浏览视野|
|vendor/m06/|M06 platform-v1 原型驱动的按字节副本，固定哈希在runtime-lock|
|scripts/integrate.mjs|向明确选择的 M06 开发副本写新增 JSON；核心源码不修改|
|scripts/fork.mjs|从已有底图创建独立草稿，引用自己的地图ID|
|tiled/|对象层导出，暂不支持改后自动导回|

## 扩展约定

基础几何、角色能力、角色适配、音频映射与制作状态分开。不得通过复制一整套游戏闭包来新增关卡。新角色只能声明已经实现的能力；攀墙、俯视移动等必须先新增并验收驱动能力。M06正式泰拉角色仍被旧运行入口约束，不能仅更换 map ID 就迁入这些模板。

底图编译器可接受世界1–8的关卡ID；本包仅提供第一世界数据。其他世界在加入已核验参考时延伸源集合和清单，不能把同一模板改名后标成新原版地图。未来的编译器版本必须清楚标注新增支持的宏。

工作台复用M06的碰撞/单向平台/场景生命周期作为数据契约验证，不宣称原版模拟精度。模拟固定60Hz，显示和输入分离；DOM控件不捕获游戏按键，画布获得焦点后才响应。焦点离开与页面隐藏会暂停。

## 保留的边界

本次不修改主站主题/小图标/路由实现，不改变已发布游戏，也不改变 M06 当前源包。地图工具包有独立0.1.0/K01版本。公开项目状态从campaign生成；原游戏TASKS与旧交接不被迁走或覆盖。
