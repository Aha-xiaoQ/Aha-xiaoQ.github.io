# 混合马里奥 · 关卡模板 K01

第一世界的地图开发资料与测试工作台。与第三期游戏工程配合使用，不替代任何已发布关卡。

**现状**：1-1 魂斗罗/洛克人，1-2 忍者龙剑传/坦克大战，1-3 泰拉瑞亚已有发布试玩；1-4 奥日开发中。制作状态由维护者确认，底图核验和正式角色接入分别记录。

本包有 **4 份坐标转录模板、8 个房间**。2-1 至 8-4 只登记管理位置，尚未提供底图。敌人、奖励与未实现机关以定位标记保留；几何测试角色不是原作角色或原作物理。

```sh
npm run verify
npm run dev
```

浏览器打开 http://127.0.0.1:4195/ 。需要 Node.js 22+，无需 npm install。地图可按房间浏览、横向移动视野、开关对象标记，也可测试单跳/二段跳的路线。测试时先点画布，再按方向键/AD、空格、E、P。

开发顺序见 docs/START_HERE.md；具体接入见 docs/INTEGRATION.md；保真边界见 docs/FIDELITY.md；后续计划见 docs/ROADMAP.md。来源和使用范围见 NOTICE.md。
