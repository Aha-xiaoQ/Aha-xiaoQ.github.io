参考对象

JayPavlina/super-mario-bros-crossover 的 README 说明，这份代码对应 Flash 游戏 3.1.21，图形与声音素材不包含在内。历史研究固定在提交 83974eb7b3d554b9c8c5da07f64bfd608f3f65fc。

取其组织思路

Character、Bill、SoundManager 与 LevelData 提供了角色差异、音频管理、关卡数据等职责划分的参考。本项目继续使用自己的浏览器实现，不搬运 Flash 的大型继承结构。

代码与素材分别核验

上游仓库的代码许可并不自动说明第三方角色、图像和音频可以再分发。未核验素材保持待确认，不把“网上能找到”当作许可。
