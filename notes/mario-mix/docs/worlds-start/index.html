返回项目资料 · 地图工坊与关卡模板（实验）

从工具页打开地图工坊，即可开始制作。

选择地图

选择“从底图创建”，按世界、关卡与区域加载参考地图；也可以新建空白地图。编辑的是自己的副本。

编辑与试玩

放置地形、敌人和奖励，调整后点击“试玩地图”检查效果。角色菜单可选择马里奥或魂斗罗比尔，不同角色使用各自的操作方式。

保存与离线游玩

保存工程文件，便于下次继续编辑。需要分享或离线游玩时，使用工坊内的 HTML 导出功能；下载后用浏览器打开。HTML 用于游玩，继续修改地图请保留工程文件。

反馈问题

提供地图工程、所选角色、浏览器与设备，以及能够复现问题的操作步骤。
