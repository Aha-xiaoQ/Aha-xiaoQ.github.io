历史版本资料

本文对应标题中标注的版本；当前源码和验收状态请查看项目资料。

自动检查：npm run verify → npm run prepublish:check。记录 dist/build-report.json 的候选 SHA。

实机路线

  1. Windows Node 22+ 执行命令、检查路径与 junction 保护。启动真实 HTTP 模块入口与单文件候选，确认资源/CSP/模块加载。

  2. 全新浏览器配置打开菜单；提示条不阻挡开始。打开手册、Tab/Shift+Tab、Escape，检查焦点与世界输入不串用。

  3. 游戏中/已暂停时分别打开关闭手册，离开标签页、返回、前进后退，确认无意外自动恢复，按钮仍能用。

  4. 改键后重新打开手册；实体手柄/触屏/热插拔与按住按钮关闭手册均测试，记录设备与映射。

  5. 导出反馈在剪贴板拒绝时可手动复制；不会发送数据。禁用本地存储时仍可操作；刷新后检查偏好保存状态。

  6. 常用桌面、320/390px手机、横屏、200%缩放、高对比与减少动效，注意像素HUD没有宣称缩放支持。

  7. 自然完成第三期地表、地下、Boss、奖励和返回；听音频衔接，检查存档与异常恢复。

  8. 网站当前源码链接、版本、源ZIP哈希、任务状态与三个主要资料入口；历史链接仍可访问。

Windows、设备、音频、自然通关、真实网络加载、真实BFCache及上线结果未由离线DOM测试代替。将证据写入 RELEASE_REVIEW.json；没有完整证据时保留 pending，不能用自动检查当人工批准。
