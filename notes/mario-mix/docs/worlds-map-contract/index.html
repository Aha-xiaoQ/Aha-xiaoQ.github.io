32 关均为社区版本参考转录，不是任天堂官方地图，也未完成与原作的独立逐格、逐帧核验。删除了纯背景装饰，保留地形、敌人位置、物品记录、区域关系和条件段。

坐标与预览

参考 8 单位为一格；输出 16 像素为一格。x_out=2*x，y_out=208-2*y；检查视图高 240。普通对象保留宽高；向下无限延展的对象截取到视图底部。超出预览边界的原记录仍在 reference 和 semantics/markers 中，coverage 标明裁剪。

世界 2–8 的预览宽度从几何、平台范围与可见对象计算，不是原作固定屏数。6-2 水下有一个参考坐标为 x=1220 的珊瑚，因此预览范围包含该异常记录；未擅自猜改为 120。详情见 SOURCE_REVIEW.md。

循环与水下

4-4 有 3 个条件段、7 个分段视图；7-4 有 7 个条件段、18 个分段视图；8-4 有 3 组循环区域、8 个分段视图。before/stretch/after 各自保留局部坐标、声明宽度与 pass/fail/section 目标。

不是把这些段一次拼接就得到原版关卡。动态伸展、判定与循环要由场景驱动实现。5 个水下区域完整保留地形和环境声明，但不导出成假游泳关卡。

几何检查与正式玩法

世界 2–8 的平台协议只提供分区检查，不运行跨区域传送、藤蔓返回、游泳、完整敌人、道具奖励、弹簧、联动平衡台、循环电梯、旋转火焰棒或城堡结算。平衡台、弹簧与桥的初始形状是可视/碰撞参考，不是已实现机制。

源入口保存在 topology，inspection-start 是独立调试出生点，不能当成原版入口坐标。运动平台使用实验时序；无效范围保留为待核验标记。

验收

模板数据存在、参考转录一致、原版独立核验、机制实现、角色接入、自然通关与发布批准分别记录。不得从模板测试数量推断发布完成。Tiled 仅导出对象层，编辑后不会自动回写。
