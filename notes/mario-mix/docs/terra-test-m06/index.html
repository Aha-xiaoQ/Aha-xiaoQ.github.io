验证边界

记录基于 Linux、Node 22.16.0、Chromium 与 Python Playwright 的离线候选测试，使用内嵌媒体并阻止远程请求。部分场景由测试接口预设，pagehide 为合成事件；未执行自然完整通关。独立 Node HTTP 检查不代表浏览器 HTTP/ESM/CSP 网络验收。

待验收：Windows 与 junction、实体手柄和触屏及热插拔、刷新存储、原生全屏、音频听感、自然关卡与隐藏挑战、真实网站下载与部署。测试数量不代表设备覆盖率或通关率。

复现

运行 npm run verify、npm run prepublish:check、npm run test:polish-browser、npm run test:browser。浏览器检查需要已有 Playwright 与 Chromium。
