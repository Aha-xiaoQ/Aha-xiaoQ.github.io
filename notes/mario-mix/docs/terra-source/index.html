运行项目

需要 Node.js 22 或以上，无需 npm install。解压源码，在工程根目录执行：

npm run build
npm run verify
npm run prepublish:check
npm run dev

试玩与操作

启动后访问 http://127.0.0.1:4193/play.html。角色选择中标明关卡；操作、按键和游戏设置从顶部进入。

界面升级包含清晰 HUD、窄屏快捷栏、角色操作说明及最近提示。重新开始和切换角色会先确认。

修改界面与参与开发

当前 HTML 入口为 src/app/player.template.html。文案、界面交互和 HUD 各有独立模块，见 UI_CONTRACT.md。修改 src 后重启服务并刷新，不编辑 dist。

从项目任务页选择改进，按 CONTRIBUTING.md 运行检查。地图、战斗与素材沿用第三期底稿，本版没有新增正式关卡。
