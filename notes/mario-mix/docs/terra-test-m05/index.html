历史版本资料

本文对应标题中标注的版本；当前源码和适用范围请查看项目资料。

2026-09-17；Linux、Node 22.16.0、Python Playwright 与 Chromium。记录针对 M05 开发候选，不代表当前线上版本的验收结果。

已记录的覆盖

  • 153 项 Node 测试通过，零失败或跳过，包括原有 138 项与 15 项 UI 模型、绘制、输入边界及样式检查。

  • 原版重建 SHA 与参考 HTML 一致；候选支持单 HTML 与模块网页两种构建形式。

  • 完整原版与候选脚本离线对照 13 阶段，无状态差异。

  • 新 UI 离线 DOM 35 项检查覆盖开始、专注、改键、显示偏好、Space/Escape、动态键位提示、原工具点击、五档视口与大号对话框，无未捕获脚本错误。

  • 设置窗口 25 项、关卡原型 21 项、普通玩家入口 6 项回归通过。

验证边界

浏览器测试离线执行完整候选与内嵌素材，保留 CSP 并阻止远程请求。随机、时间与隐藏场景条件由测试接口控制，未执行自然通关，也未验证浏览器真实 HTTP/ESM 加载。

大号偏好检查 CSS 菜单正文 20px；固定像素 HUD 不随此设置放大。320、390、768、1440 及 844×390 视口未横向溢出，真机可读性仍需检查。偏好模型覆盖独立存储键与存储失败，浏览器刷新和权限待验收。

未验收：Windows 原生 CLI 与 junction、实体手柄和触屏、刷新持久设置、音频听感、自然通关、真实网络与部署、外部 PR 和第三方许可审批。减少界面动效不关闭游戏世界的震动或闪光。
