对应哪个版本

本工程整理自已发布的第四期 R43（索尼克 × 奥日，1-4）。保留原有游戏内容、地图、声音与素材声明；它不是第三期 M07 源码的替代品，也不代表通用运行时角色迁移完成。

未改动源码时，可以重新构建出与 R43 发布 HTML 逐字节一致的单文件游戏。第四期在线试玩继续保留，不会被源码构建自动覆盖。

下载与启动

解压源码，在工程根目录使用 Node.js 22 或以上版本运行。无需 npm install。

启动后访问 http://127.0.0.1:4194/play.html。Windows 也可双击源码包内的 start-dev.cmd；端口被占用可改为 npm run dev -- --port 4195。

npm run verify
npm run dev

源码如何组织

src/app 为页面壳，src/styles 为 6 组样式，src/runtime 为 26 个按顺序编译的逻辑片段；src/data 保留音频及拾取配置。assets/audio 与 assets/images 收录从现有发布 HTML 提取的 260 个去重素材。

源码片段仍共享原版作用域，不是可任意逐个 import 的独立模块。编辑后运行 npm run build，产物为 dist/play.html；完整导航见源码包 START_HERE.md 和 docs/MODULE_MAP.md。

npm run check
npm run build
npm run pack

音乐、来源与验收边界

上升段保留原 R43 的 Restoring the Light, Facing the Dark 48 秒高潮循环音轨，使用原生音乐通道。不替换原有地图、角色动作、BGM 或音效。

源码构建校验不代替真实设备、手柄、音频或自然通关验收。第三方角色、图像与录音的权利归各权利人；本次整理不扩大原有授权。部分历史资源仍保留外部回退地址。
