历史版本资料

本文对应标题中标注的版本；当前源码和验收状态请查看项目资料。

当前UI将主要HUD与菜单文字分层，但未将所有兼容区的世界内文字迁出。移动设备全屏、实体输入、读屏、网络与自然通关需实机验收。WorldKit W02依然固定M06；其模板数据并未自动获得本版界面或完整角色跨图能力。

已支持

运行第三期开发候选；修改已迁出的输入、设置、Boss 基础、建造和物品规则；重建原始底稿；创建限定能力内的地图与几何角色组合；构建并打包源码。

尚不支持

  • 完整泰拉角色、背包、武器与坐骑直接用于任意新地图。

  • 全部原版地图与通用机关；本版不包含完整 1-4。

  • 将 platform-v1 视为旧角色的物理实现；它是单独的关卡原型驱动。

  • 完全离线的所有可选资源；部分素材仍有远程依赖。

待验收

Windows 原生运行、真实 HTTP/ESM/CSP 加载、实体手柄与触屏、持久配置、音频听感、自然通关及 GitHub CI。请在对应记录中填写设备、候选校验值和复现结果。

自动测试覆盖的条件见 M05 历史测试报告；发布需要 人工审批记录。未填写的项目保持待验收。

发布与许可

开发候选与线上试玩分别维护。项目为非官方作品；代码公开不代表全部第三方素材取得再分发授权。请保留 NOTICE 并逐项核验素材来源。
