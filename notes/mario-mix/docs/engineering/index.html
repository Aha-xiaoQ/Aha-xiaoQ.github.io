从一处小改动开始

当前第一处可独立修改的模块是第一期比尔的瞄准与下穿输入意图，源码位于 packages/mario-mix/src/input/。原游戏其余部分保留；第二、三期没有在这一轮完成模块化。

先测试，再对照试玩

使用 Node.js 22 或更高版本；本工程没有第三方 npm 依赖。候选试玩使用独立的本地端口，不覆盖线上游戏。先在 Issue 中确认任务范围，提交 PR 时附测试结果和候选构建校验值。

npm run game:check
npm run game:test
npm run game:audit
npm run game:build
npm run game:dev

尚需确认的部分

本地测试通过不代表完整游戏通关、实体手柄或音频验收通过。素材和游戏代码授权仍需逐项核对，不能因为有协作工具就认定整个游戏已采用开源许可。
